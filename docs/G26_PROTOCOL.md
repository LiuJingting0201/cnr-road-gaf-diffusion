# G26 — change diffusion training, not the sampling-time score
Train on G22's 6,033 completed trips. Reuse its 12,000-update monolithic baseline (single clock plus 256 increments). For each new arm jointly denoise the clock, 16 coarse distance shares over relative-time blocks, and 16 nonnegative local distance shares inside each block. Normalize within block and over the full route so the destination is reached. Both scales are learned in one denoiser; this is not a cascade of separately trained networks. Keep G22 backbone, updates, batch, class-balanced row selection, route encoder, sampler, seeds 42/43, K=4. Multiscale has 273 rather than 257 latent entries and an extra coarse loss. Disclose this computation difference.

Four new arms: H (hierarchical progress), HM (+ G23 training mode condition), HV (+ direct physical speed-curve supervision on the predicted clean trip), HG (+ speed GASF/GADF supervision on the same predicted clean trip). Mode sampled from class- and route-length-specific training prior at inference, never from the observed future; identical target across conditioned comparisons. Curve and field losses use the same speed samples, fixed absolute scale, smooth alpha weight and loss coefficient .1, each normalized by its own mean training-pair disagreement. Speed supervision is not the inherited spatial Hilbert image. The spatial reader remains a separate independent check. No post-hoc GAF selection during the main training comparison.

Lock co-primary evaluation: per-class W1 of longest steady-moving duration and travel time on eight fresh same-map SUMO episodes 277001–277008; first six supported routes per class/episode, sorted ID. Secondary four-second speed-change W1, within-condition diversity and requested mode match, endpoint/cap checks. Compare H to G22, HM to H, HG vs HV and vs HM. Whole-episode paired bootstrap conditional on two fitted weights, no hyperparameter search, no original test or G15 reserved observations. Fixed development check and negative findings retained. For context on coarse/fine long-motion synthesis see Lodge (Li et al., CVPR 2024); no priority claim for multiscale diffusion.

Before inspecting any G26 generation scores add a secondary fixed-route switch test. In each class take its training speed band with the most-supported pair of steady/variable regimes, requiring at least 40 training trips per regime. Hold route, class, checkpoint and noise fixed while switching only the speed-mode label. Compare changes in measured four-second speed variation, cruise and trip time, with class-balanced episode intervals. This identifies a within-model response, not observational ground truth for the alternate counterfactual.
