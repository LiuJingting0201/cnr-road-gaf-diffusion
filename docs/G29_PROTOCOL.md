# G29 · 对照原始 CNR，定位空间识别差距

用户于2026-11-06要求先诊断原始CNR与新SUMO的数据/编码差异，再考虑生成实验。本轮仅作数据和表示诊断，不训练生成器，不扩写论文，不修改旧结果或冻结测试。

原CNR正控制来自 midimost 六类原始数据，原E1完整观察ID的64网格预训练ResNet18宏F1约60%。TS文件只有veh_passenger，不能支持车型分类比较。G28八类低分与E1六类高分存在类别、人口、记录定义和划分差异。两者训练更新数近似相当，不能凭18与50轮数推定训练不足。

## 数据
仅使用原CNR既有train/val ID和G22新SUMO的train/monitor场次。原数据为观察记录，无原始到达文件，完整ID可能有时间缺口。主对照使用最长连续0.25秒轨迹段，至少5秒。两源保留共同六类，按每类最小可用人数匹配，在各自原分区中抽样，seed29042。原CNR训练边界、Hilbert eps=.0009、224长度与原RGB通道尺度均冻结复用。保留全观察记录用于核对原E1正控制，避免把连续段定义偷换成原实验。

附加两项敏感性对照。第一，在相同类别人数下用类内无放回Hungarian匹配选择最接近原CNR时长的新SUMO记录，报告匹配残差。第二，两源仅选足够长的ID，每条取中心512点即127.75秒，重新匹配每类人数。这些子人群与主对照不同，需要报告资格和计数。

## 编码分段与同预算读出
在相同ID上生成以下输入。XY为原坐标按观察索引重采样至224点，使用公共空间边界。Hraw为量化后的原生Hilbert序列直接重采样至224点。Hsqueeze为继承的驻留压缩和镜像补长序列。Hunit为对Hsqueeze逐轨迹min-max归一化的序列。RGB为继承的GASF/GADF/MTF图像。

前四组使用相同两通道1D CNN架构，单通道Hilbert补零第二通道，固定50轮、两种子。RGB用与E1相同ImageNet ResNet18、逆平方根频数权重、AdamW lr2e-4 weight_decay1e-4、batch64、固定最后第50轮、两种子，不按验证集选择配置。保存训练分数、验证预测、逐类召回和宏F1，防止把优化不足当成信息不存在。主对照20拟合，512点RGB四拟合，时长匹配SUMO RGB两拟合，共26个预定拟合，无调参扫描。

浮点GASF对归一化序列满足u_i=sqrt((G_ii+1)/2)，因此单独实测对角恢复误差及uint8恢复误差。量化、压缩、归一化的影响分别描述。XY和Hraw都经过重采样，不能把二者的学习分数差当作纯粹的信息论损失量。Hunit与RGB使用不同架构，图像分类差距须结合确定性可恢复性解释。

## 数据结构诊断
同一固定读出分别预测仅几何特征和仅物理运动特征。读取类条件位置、路线占据、长度、时长、速度、加速度和停止比例。几何支不输入时间或显式速度。运动支独立标注。比较验证轨迹与训练轨迹的按弧长重采样路线RMS近邻距离、近邻标签一致率及100/250米覆盖。原始单份导出上的ID划分和新数据按场次划分的差异需要明确，不能把空间重复自动判作错误泄漏。

主要回答三个问题。相同编码相同标签条件下源分布差距有多大；相同源内哪一转换阶段改变可读出信息；几何与运动的类别关联在新SUMO是否变弱。不能由某一低准确率宣称无任何信息，也不能由原CNR较高分宣称识别了运动机理。

小样本类（原验证出租车9、公交14）需逐类报告；按ID自助法区间条件于原开发划分和两种子，新SUMO只有三个监测场次，不构成真实场景泛化证明。保存配置、源哈希、失败和小型指标，只在完成诊断后决定是否以及如何恢复生成实验。

在查看新拟合结果前，补充量化坐标控制grid_xy。只将公共归一化XY量化至64×64格中心，再按相同索引重采样至224，使用同一两通道1D网络。它直接比较量化前后的坐标，避免将Hilbert的非线性顺序或网络读出困难误归为网格丢失。两源两种子共4拟合，合计30个固定拟合。原计划各组保持原定义。
