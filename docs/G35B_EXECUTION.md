# G35b：并行执行修订

2026-11-07，启动前固定。本修订替代 G35 协议的顺序执行、全车辆 FCD 记录与 12 GiB 仿真上限；其余科学设计、模型和训练预算保持。

v1 首场运行约 60 分钟已写出 6.34 GB，继续记录三场全部车辆将超出本轮存储预算。该尝试取消后保留，不作为完整数据成果。

新隔离目录 `g35b-job` 同时执行 350101、350102、350201 三场 CPU SUMO，各自完成后提取，最后合并并自动接原定四扩散、两教师训练。GPU 用于模型训练，SUMO 并行依靠 CPU。

全交通、行人、线路、站点、活动链、10 小时时间范围和 0.25 秒步长保持。仅在仿真前按公开需求 ID、原 CNR 分区、G30 未知 ID 分区及 G35 训练种子分配确定 FCD 记录对象；包含公交和高速 flow 的潜在目标类别分布，不读取实际类别、完成状态或评分选择记录对象。FCD 保存 x/y/type/lane，自动保留 id/time；速度 GAF 仍从原始 XY 与时间推导，未写出的 speed/pos 辅助字段留空，不补值。

名单、克隆 SUMO 配置、解析回执、源码和输出均哈希。记录选项变化是否保持相同随机实现尚未验证，不能提前宣称同 seed 逐点不变，也不把三进程直接称作三倍提速。

新目录上限 15 GiB，空闲保留 8 GiB。并行目录统计允许临时 JSON 原子重命名期间文件消失。旧尝试仅本轮自有的大型 FCD 可迁移到本地忽略目录，完整下载并核对源 SHA256 后才删除服务器副本，保存归档回执；旧工作树、权重和其他历史结果不删除。

此文件为部署前记录。实际启动、吞吐和完成状态另记，未新增质量结果，论文暂不更新。
