# G23 — spatial class feedback versus speed-pattern feedback
Use the frozen complete-trip OD generator and the same four candidates per request/seed. The spatial branch is the native-cadence whole-trip Hilbert–GASF/GADF/MTF classifier. Its only input is ordered XY, and its only target is participant class. Motion naturally affects time-ordered positions; no explicit velocity, acceleration or motion-CNN output is fed into this branch.

The speed branch is a separate ResNet18 looking only at angular images of the complete speed series, with six behavioural targets and no participant labels for CNN fitting. Define the targets using training-only tertiles of trip-mean speed and, within each band, the median four-second speed change (steady vs more variable). The participant class enters only at generation time through an empirical conditional distribution of speed modes among 64 nearest-length training routes of the requested class. Draw one target mode per request using a reproducible random number, independent of its validation reference. The class-blind control draws from the 64 nearest training routes regardless of class using the same random number. Rare/frequent modes can occur; vehicle class does not prescribe a single style.

Lock before results. Compare uniform, trajectory class score, speed mode score (class prior), speed mode score (class-blind prior), equal rank combination of both class-directed scores, and a direct numeric mode match as a cheap baseline. Use identical frozen candidate pools, both model seeds and no reference during selection. Primary population: eight fresh independently seeded same-map SUMO episodes (275001..275008), 48 requested participants per class per episode; retained completed trips only. Class-macro W1 of longest continuous steady-moving duration and trip duration are co-primary, lower better. Secondary: mode-frequency total variation and four-second speed-change W1. Compare against uniform and each other with paired whole-episode bootstrap, conditional on both checkpoints. This compares operational feedback policies with different targets, not two representations trained on identical labels. No legacy holdout access, no winner guaranteed. The inference mechanism is post-sampling reranking; no claim of in-loop guidance.
