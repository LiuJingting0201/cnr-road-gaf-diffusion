# 毕设主线与答辩开场

**拟题：路网与交通参与者类别条件下的完整行程扩散合成。副标题：空间轨迹与速度模式反馈的比较。**

## 开场
给同一辆公交车一个起点、一个终点和一条许可路线。地图能确定它可以走哪些路，却不能确定它在哪里减速、巡航多久、几点到站。我们的任务是在不给真实未来和到达时刻的情况下，生成多趟可能的完整行程。打开模型包里的公交示例：同一条 2.34 公里路线，四条候选分别在 228、242、280、308 秒到达。每一条都是一份可以导出的 time,id,x,y,type 数据。

## 论证顺序
1. **生成什么，哪些量由模型学？** 接受路网、起终点（或一条事先规划的许可路径）与类别。规划器给路线；扩散联合采样整趟时长和相对时间内的前进量；解码器保证端点一致并按真实秒数输出。以 SUMO 的实际到达记录区分完整行程与被截断观测。CNR 原始表格用于早期重建和固定窗对照；完整 OD 模型另用独立 SUMO 场次训练与验证。
2. **怎样判断它真的会动？** 分开验证路网连通、旅行时长分布、持续巡航及弯道速度。在固定路线与噪声、只换类别的短窗干预里，识别的是生成器的类别响应。在完整行程上，端点是结构保证，时长与过程是学习对象。需同路线、同类别的经验迁移作为对照，完整行程时长分布目前未证明扩散更优。
3. **如何承接组内 GAF？** 对同一条完整候选保留两种读法：有时间顺序的 XY→Hilbert→空间轨迹图，用于识别参与者类别；XY→整趟速度序列→速度角场图，用于识别速度模式。速度分支的 CNN 不猜车型。类别通过训练侧“同类、相近路线长度”条件下的模式分布影响所请求的风格。两种图表达互补信息，不能用不同任务的分类率判谁对生成更有效。
4. **结果允许说到哪里？** 在八场全新流量下，每种策略从相同四条候选交付一条。空间反馈对总时长分布更有用，速度反馈相对均匀选择改善四秒速度变化；持续巡航时长没有明确赢家。这里只验证采样后筛选，不能称为采样中梯度引导，也不证明任意城市或真实公交服务上同样有效。

## 哪些材料放后面
512 点是局部运动的控制实验，不是最终轨迹长度。固定某一步的 GAF 干预、网络结构扫描和分类准确率归入诊断。讲述次序以“完整输出 → 时间和运动质量 → 两种反馈的边际作用”为准。主张是一个可运行、可核验的路网约束合成方法及其适用边界；避免把设计保证、样本数量或分类分数当作生成质量的证据。
