# G24｜采样中速度 GAF 能否提高最终轨迹 GAF 的目标车型分数？

冻结 G22 整程扩散、G23 速度模式 CNN，以及只在采样结束后调用的八类空间 Hilbert–GAF CNN。在8场新 SUMO 车流中选取192个起点／路线请求，八类各24个；每组两模型种子、四噪声，共1,536条完整候选。各组使用相同路线、初始噪声和100个反向步。主实验强度事先固定，随噪声水平平滑变化，没有选特定时间步。梯度来自估计的速度曲线及可导的 GASF/GADF 通道，MTF 不反向求导；采样沿规划路径，最终指标从解码坐标重新计算。置换对照在请求间打乱目标模式并保留总体频率。原测试及 G15 预留未访问。

| 策略 | 速度 GAF 目标模式平均概率 | 轨迹 GAF 目标类别平均概率 | 轨迹 GAF 判为目标类别的比例 |
|---|---:|---:|---:|
| 普通扩散，全部候选 | 36.39% | 23.70% | 23.18% |
| 采样中速度 GAF 引导，全部候选 | 38.00% | 23.88% | 23.83% |
| 置换目标后引导，全部候选 | 35.00% | 23.88% | 23.89% |
| 普通扩散，末端速度筛选 | 64.52% | 24.69% | 24.22% |
| 采样中引导，再做末端速度筛选 | 66.29% | 23.53% | 22.66% |

速度得分按原始正确模式评价所有策略。主比较：速度目标概率提升1.61个百分点 [0.88,2.35]；目标空间类别概率提升0.19个百分点 [−0.24,+0.65]，与置换目标组的差约0.00个百分点 [−0.49,+0.45]。实际解码轨迹分别用物理规则划入目标速度模式的比例仅增加0.46个百分点 [−0.78,+1.76]。四候选末端筛选时，额外加采样中引导相对只做末端筛选的空间分数变化为−1.15个百分点 [−2.35,−0.05]，为次要比较。区间按整场仿真配对重采样，条件于两个冻结模型。

不筛选候选时，生成相对无引导的最长巡航 W1、总时长 W1、四秒速度变化 W1 差分别为−0.46秒 [−1.41,+0.43]、+0.43秒 [−0.15,+1.14]、−0.0034 m/s [−0.0122,+0.0103]。没有可靠整体质量收益。每种子单卡普通采样约5.3秒，正确模式引导约22.5–23.4秒；相同候选预算的算力并不相同。编码失败、时长触界、平坦曲线回退均为零。

事后诊断（不作为预先指定的主证据）：将同一噪声的引导版时长与无引导版途中进度重新组合，原空间类概率变化约+0.36个百分点 [0.08,0.67]；只替换途中进度约−0.25个百分点 [−0.52,+0.03]。两项经过非线性空间编码后不能相加；这不是另一个已验证的引导策略。完整引导改变时长平均约9.3秒，整体的空间分数变化仍不明确。研究结论仅针对本次强度、模型、速度模式定义和仿真车流。
