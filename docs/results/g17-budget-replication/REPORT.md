# G17｜扩散训练预算、独立复核与八类模型交付

全部四个训练臂、两个种子均完成 20,000 步；和 3,000 步是两组从头训练，不是同一权重沿途的两个 checkpoint。A=仅 CNR，D=CNR 加每类 85 个 SUMO ID，B=CNR 加可用五类 SUMO 训练全集，C=八类扩散。D/B/C 对原五类均按来源 50:50 抽样。主终点是独立 G14 上 B−A 的五类宏平均行程 W1（米，越小越好），评估条件只用起点、类别及许可道路规划，参考未来在生成后才用于评分。原 CNR 测试和 G15 留出均未用于本轮。

G14 主比较 B−A = −23.5 m [−70.7,+6.4]，两种子分别约 +1.8 与 −48.8 m；训练种子有限，尚不能声称独立行程收益稳定。G14 B−D = −7.1 [−31.4,+16.2]，控制混合比例后，全量新数据相对单一小样本子集的进一步收益不确定。G15 B−A = −69.2 [−109.8,−14.4]；相对原数据模型，G16 的短预算点估计方向相反。CNR 原开发只报告点值，避免把新开发评价写成冻结测试增益。区间按整场仿真重采样，条件于固定的两个权重与噪声，未调整多指标。

G14 的平均绝对加速度分布差异 B−A = −0.225 m/s² [−0.285,−0.151]。同一路径上各候选两两之间的平均位置距离（按类宏平均）从 58.3 增至 120.1 米。这表示有更多轨迹变化，不证明已校准真实多样性。G14 A/B 两臂均 960/960 通过道路图检查，均无耗尽。

八类模型在 G15 175 个起点（21行人，其余7类各22）合成 1,400 条 512 点轨迹。1,232 条车辆／自行车轨迹通过有向车道图检查；168 条行人轨迹通过预定单段人行道距离检查。规划筛选中有 301 个不合格行人起点。7条自行车轨迹耗尽给定路径，均保留。公交行程 W1 为 197.9 m，高于其他类别；默认仿真没有时刻表。归档包括所有候选，权重包固定种子42，并在 CUDA 以独立命令实采四条轨迹。代码、指标与记录可在 Git 获取；权重与坐标仅通过单独的数据包交付。

GAF 复核使用既有原编码、自训且冻结的 G12 seed42 校准 CNN；在 B 的 960 条候选上编码失败为 0。相对同池均匀选择，选中候选对参考时间窗的速度分布 W1 差 +0.052 m/s [−0.107,+0.204]。交付行程 W1 差 −1.7 m [−60.7,+46.4]。这一独立复核未显示可靠改善。不将已有六标签网络用于新货车／配送车类别。首次推断因缺少原编码 vendor 导入路径失败，保留错误日志并修复路径；模型与评价标准未变。
