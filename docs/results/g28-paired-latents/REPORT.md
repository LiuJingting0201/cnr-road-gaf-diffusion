# G28 · 对齐双 GAF 车型潜空间后的完整轨迹合成

2026年11月6日完成。4个同标签教师、12个扩散拟合全部通过完成标记；所有扩散臂各12,000步、两种子。6,033训练轨迹和1,126监测轨迹按场次分开。八个新需求种子279001–279008产生3,018/3,072条合格参考，按固定ID规则选384请求、每类48。每臂3,072候选，全部进入物理评价。原CNR和G15冻结测试均未访问。

## 表征主张得到哪一级支持
两位自行训练的CNN均预测相同八类参与者，空间支只读原Hilbert/GASF/GADF/MTF，速度支只读从原生带时间戳坐标计算的速度GAF/MTF。统一原始端点策略，ImageNet初始化、输入尺寸、拟合预算和监测规则一致。

冻结seed42特征、训练侧固定PCA及逻辑回归，在八场新车流上进行独立读出。宏F1为空间23.69%、速度60.83%、拼接56.13%、仅路线24.85%、两项物理统计38.36%。只研究六机动类别时，空间17.93%、速度47.69%、拼接43.11%。拼接相对速度宏F1差−4.70个百分点，场次区间−7.62到−1.77。拼接拥有双倍维度，有限样本和固定正则亦会影响结果。这能证明当前速度表示有可读出的类别信息，未建立当前空间表示的额外益处，不能推断所有非线性融合均无互补信息。

## 实现与表示审计
原空间训练补人工端点而后来评价未补，现已统一。96个预定监测样例的旧教师准确率原始30.2%、补端点31.3%，这项差异无法单独解释低识别率。真实目标经过轨迹表示和道路解码后的各类均值速度曲线MAE约0.02–0.26 m/s，已保存全部分位数。空间压缩存在将两倍时长的同路径映射成相同序列的确定反例，见G28_AUDIT。

首次新仿真链接到了旧五类源码，出现truck未注册，随后切换至既有G22八类环境并重跑八场，旧失败日志留于服务器。缓存和重构审计最初重复解压NPZ，改为每场只解压一次后重启本轮进程。主干同初始化、EMA独立hook、仅辅助损失的非零反向梯度均已实测。无模型超参数扫描。

## 可写入论文的结论
当前速度GAF保留可读出的车型统计信息。同标签、同数据、相同预算的潜空间监督直接检验了用户提出的新命题，但尚未转化成稳定的额外合成收益。给定路线和类别后，能够分类的信息仍可能重复已有条件。空间编码的信息损失、随机路线和默认车型的行为重叠限定了原编码在当前新仿真数据上的价值。G28不能证明原CNR数据或其他融合方式无效，也不能宣称GAF优于原始时序表示。

本轮按预定六臂停止。下一项需要证明的是与车型和路线条件相比额外保留的类内时序信息如何控制生成；当前结果不支持只提高分类分数或加大同一损失系数作为论文贡献。论文第十五稿将信息读出、训练传递、物理生成三层证据分开组织。
