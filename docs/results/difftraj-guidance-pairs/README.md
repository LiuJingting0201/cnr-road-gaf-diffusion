# Sampling guidance on supported bus and bicycle requests

This development probe reuses the two final class-conditioned checkpoints trained without auxiliary speed loss. Each of the 113 pre-existing matched pairs supplies two headers. For each header the sampler generates with both vehicle labels from the same initial Gaussian noise. Direct-label samples are scored against observed trips on the common 200-point physical clock and by the four existing distribution metrics. Signed label contrasts are bus minus bicycle. Every variant uses one sample per label and 100 DDIM transitions. No validation trajectory is used as a speed target.

The baseline retains the released trip guidance and the trained vehicle embedding. Class contrast adds half the difference between the predicted noises for the requested and alternative vehicle labels at every step. Speed guidance obtains five speed quantiles from the 32 training trips of the requested class nearest in standardized duration and trip-average speed. A gradient on the estimated clean positions encourages agreement between smoothed speed order statistics and those targets. The step in the estimated clean path is capped at two metres times cumulative signal power and leaves the two estimated endpoints untouched at that step. These are specified pilot strengths. Speed quantiles describe the distribution of speeds within a trip and do not specify the order of stops.

Coverage is the common-support subset of the existing validation requests. Comparisons use fixed weights and training seeds 42 and 43. The frozen test split is excluded.

On these 226 requests speed guidance reduced bus speed W1 from 1.014/0.885 to 0.985/0.850 m/s and reduced the bus low-speed-time deficit from 19.38/17.69 to 17.64/16.11 percentage points. The bicycle low-speed fraction moved slightly too high. OD JS was unchanged to four decimal places. Class contrast produced larger bus speed W1 improvements, but OD JS increased from .0869/.0870 to .1538/.1270. Both approaches increased the bus-minus-bicycle slow-time difference at fixed headers. The resulting contrasts still cover only a fraction of the 41.94-point observed difference. Files report the original and guided results for each checkpoint.
