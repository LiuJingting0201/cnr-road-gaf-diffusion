Generate full vehicle runs on the public Monaco MoST network with SUMO. Per class target 10,000 train, 1,000 validation and 1,000 test. One episode-specific ID per trip. Bus vehicles use original bus routes and stops with dwell times; departures are randomized, not original timetable runs. Other vehicles use vehicle-specific SUMO routing on random OD requests and default class dynamics. Demand is quota-designed. Retain observed departure-to-arrival traces with continuous 1-second samples, at least 120 positions, finite coordinates, length >=100 m and maximum position step <=65 m. No teleports. Invalid and unfinished runs do not count. Fixed episode-disjoint partitions; exact duplicate 200-point paths excluded. Preserve raw simulator time, x/y metres and speed. Model arrays are float32 standardized planar coordinates [N,200,2] and aligned eight-column headers [N,8], plus separate ID and class metadata. Base time-of-day offsets are assigned by episode; this is a synthetic clock. All continuous normalizations and 16x16 OD cell boundaries fitted on training records. The script marks COMPLETE only after per-class quota checks. No real-world Porto/CNR identity is claimed.
