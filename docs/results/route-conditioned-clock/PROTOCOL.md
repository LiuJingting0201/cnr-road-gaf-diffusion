# Can generated route geometry improve a diffusion speed clock?

Retain the original retiming experiment's coordinate polylines, trip requests, sample noise, speed representation and final-epoch comparisons. Train two new velocity models, one per original seed (42 and 43), at 9,760 updates on the same 200,000 labelled MoST/SUMO trips. Compare each one with its original velocity checkpoint from the same training seed. Both clocks use the identical arc-length retiming procedure. The endpoint-loss extension is excluded from both arms of this comparison.

Training geometry is a free 100-step DDIM draw from the frozen coordinate checkpoint for the same training trip header and class. For each seed there is one such draw per training trip. The motion target comes from the corresponding observed trip. The sampled route and observed trip share a request, but their routes and bend locations can differ. This experiment tests whether a sampled route conveys useful guidance over and above that request; its data pairing does not supply observed speeds at known points along that particular generated route.

The condition comprises log polyline length in metres and 16 distance-ordered bins of cumulative absolute heading change (radians). To remove the original clock, interpolate 66 positions uniformly along the polyline's arc length and aggregate the 64 interior turns, four per bin. Standardize each descriptor using training-route statistics for its seed. Add one zero-initialized linear projection to the existing trip and vehicle conditioning. The sampler, denoising objective and optimizer match the baseline. Use final rather than best validation weights. Held-out motion measurements enter scoring only. The fixed test set remains reserved.

Score final coordinates of both methods on the same 3,000 validation requests, 600 per class. Primary measures are speed W1, requested destination-cell hits and low-speed share/entry-rate differences under a fixed-request bicycle-to-bus switch. Use the original 53 matched pairs; hold each request's originally drawn route fixed for both labels in both methods. This stricter comparison recomputes the earlier method's label effect. Also show acceleration W1, four distribution scores and the first request of each vehicle class on maps. Each map shares bounds and a speed scale within a given request.
