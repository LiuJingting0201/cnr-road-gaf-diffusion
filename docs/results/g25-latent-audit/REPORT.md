# G25｜类别概率是否低估了表征中的共享信息？
冻结两个 CNN 在分类头前的512维表示以及 G24 扩散模型。以 G22 训练6,033、监测1,126条行程确定变换、探针和原型，用 G23 的3,021条、G24 的192条独立 SUMO 参考行程评价。两组均属于先前使用过的开发场景。没有用速度训练车型分类器，没有访问两套预留测试或调整引导。

**真实行程的共享结构。** G23 整体线性 CKA 为0.573。保持车型和仿真场次，只打乱单车两种图的对应关系，置换中位数0.562、95分位0.565。仅六个机动类别时0.0108、置换中位0.0040。扣除训练侧类别均值后，八类0.0091、置换中位0.0071；再线性扣除类、长度、时长、均速与端点后0.0085、置换中位0.0083，没有明确额外对应。控制会移除部分真实信号，不能解释为不存在共有信息。较小 G24 组整体0.618、置换中位0.620。CKA 使用各分支前32个训练主成分，保留80.8%／94.8%方差，数值不是共享信息百分比。各类中心的对齐0.949，但随机置换类别名称的95分位也达到0.948。方法见 Kornblith 等，ICML 2019。

**读出和引导。** 相同空间中间层上重新训练的线性车型探针只读空间图，在 G23 上准确率25.09%，原头25.06%，G24 上25.00% vs 23.44%。按车型验证空间特征对实际速度模式的读出，在支持的32个类／模式对上平均 AUC 0.545，G24 的16个对子为0.529。速度引导相对无引导使空间探针目标概率变化+0.66pp [−0.06,+1.57]、类别原型相对最近异类的余弦 margin 变化−0.00064 [−0.00691,+0.00584]；类内目标模式方向变化+0.00322 [−0.00002,+0.00672]。行人没有足够的第二种运动模式，不纳入该类内方向指标。比较正确目标与置换目标也未确立差异。

**生成分布和参考分布。** 空间表征的类别宏平均经验 MMD²（越小越接近）从0.01419变为0.01433，差+0.00014 [−0.00119,+0.00147]。速度表征从0.02888变为0.05099，差+0.02210 [+0.01678,+0.02868]，几乎全部来自行人，其类内训练带宽很窄。六个机动类别差+0.00025 [−0.00111,+0.00233]。核带宽按分支、类固定于训练数据，不将两个特征空间的绝对数值比较。提高指定模式的概率与复现真实类别分布须分开实测。

**去噪隐状态。** 48条公交与私家车均许可道路（各24），固定路线、起点、噪声和当前状态，仅切换类别条件，估计局部车型方向。正确速度目标梯度与之的有符号余弦为0.0037 [−0.0022,+0.0114]，与置换目标差0.0011 [−0.0074,+0.0092]。不含时长 token 时也未见稳定同向。这是十个去噪位置的加权平均，不排除特定请求或位置有局部关系，更不能证明全部扩散层或非线性表征没有类别特征。首次执行缺少隔离目录地图链接，恢复既有地图后完成。

所有区间按整场仿真配对重采样，条件于固定模型，多项事后指标未作多重校正。结论：空间类别概率不足以独自评估生成质量；真实表征存在粗粒度共有结构，但替换评价指标之后，当前速度引导仍没有表现出稳定的空间类别分布收益。
