# Directed-road and interval-speed audit

Use the two frozen Porto mixed-trained models (42 and 43), their archived 3,000 mixed-cohort requests, and the original coordinates at 15-second intervals. Restore generated paths to the original point count exactly as in the existing evaluation. In Beijing replay all four fitted arms at both seeds, matching the original metrics on the same 470 validation segments, 200 elapsed-time samples per trip. Reverse the original local-metre transform. Evaluate real Beijing trajectories on that same clock. Reuse each city's reference set across all arms.

Use one offline OpenStreetMap city extract per city and Valhalla map_snap with 50 m search radius, 10 m GPS accuracy. Taxi uses taxi costing, bicycle uses bicycle, bus uses bus, and private car uses auto. Retain all requests including outside-map and matcher failures. Treat a whole trip as continuously supported if every observed point has a projected position within 50 m, every transition has forward progress along the matched route (allow 1 m rounding tolerance), and the matcher reports no break. Reconstruct traversed distance from cumulative directed-edge lengths and fractions of trimmed first/last edges. Test the maximum interval speed against generous plausibility ceilings (car/taxi 40 m/s, bus 35, bike 15); repeat at 0.8 and 1.2 times these ceilings. These are audit parameters, not posted speed limits. As a complementary statistic use the fraction of original point pairs that are both connected and speed-compatible. Match failure contributes zero passing intervals and trips. Report matched-point offsets with their coverage. Report strict whole trips alongside interval-level rates, as the all-interval criterion is duration-sensitive. The snapshot postdates the GPS campaigns and finite map coverage limits interpretation. No model is selected or updated from these scores.
