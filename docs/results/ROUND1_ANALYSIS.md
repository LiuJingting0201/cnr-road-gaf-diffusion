# 第一轮实验分析：已确认的现象与下一步

日期：2026-11-04。所有结果来自实际训练或采样。本文区分表示分类、候选筛选和生成模型学习，不能把三者的收益相互替代。当前全部为验证集探索，尚非论文最终测试结果。

## 1. R1：18 项训练完成

6 种表示 × 3 个种子，均训练4,000步，18/18成功。代码提交5c721a8；每个checkpoint由该次运行的验证macro-F1选择。汇总原始数字见 representation-r1/results.json。

| 表示 | 验证 Macro-F1 均值 ± 种子标准差 |
|---|---:|
| XY＋位移 TCN | 70.34% ± 0.65个百分点 |
| 训练尺度位移 GAF | 58.27% ± 0.77个百分点 |
| 逐窗口 XY GAF | 33.49% ± 0.92个百分点 |
| 细精度 Hilbert RGB | 18.94% ± 0.73个百分点 |
| 细精度 Hilbert TCN | 16.69% ± 1.03个百分点 |
| 原精度 Hilbert RGB | 16.04% ± 0.00个百分点 |

观察：当前64点、15.75时间单位的短窗口中，Hilbert路线分类能力很弱；仅细化空间网格不足以解决问题。保留训练集运动尺度的位移GAF明显优于逐窗口缩放XY-GAF，但仍弱于直接序列模型。

解释边界：不能据此否定原论文的长轨迹分类方法。长度整理、空间尺度、类别样本、分类架构均与历史协议不同。TCN同时使用绝对XY与位移，位移GAF仅输入位移，因此二者的差异尚不能单独归因于二维编码优劣。下一轮应增加仅位移TCN和相同位置条件的公平对照。

## 2. G1：同一候选池筛选

使用baseline-001中10,000步坐标扩散生成固定候选池；每个条件4组、每组8个候选。所有策略都只保留1/8；道路指标排除给定起点。选择器为seed42，审计器为直接序列TCN的seed43/44集成。结果文件 candidate-selection-g1.json。

| 策略 | 生成点在许可车道中心线5m内 | 独立审计目标类别准确率 | 每类速度Wasserstein距离均值（m/s） |
|---|---:|---:|---:|
| 随机 | 32.7% | 16.7% | 28.28 |
| 仅地图 | 57.3% | 17.2% | 24.89 |
| Hilbert评分 | 31.2% | 16.7% | 32.90 |
| 位移GAF评分 | 29.2% | 18.2% | 19.05 |
| 直接序列评分 | 29.3% | 19.8% | 25.18 |
| 地图＋位移GAF | 53.1% | 17.7% | 23.78 |

观察：地图筛选对几何贴合最有效；位移GAF筛选降低速度分布距离，但道路贴合变差。当前结果不支持“GAF全面改善轨迹生成”。这是同一生成器的筛选效用，不是生成器学习提升。

生成器本身明显不成熟：独立审计分类接近低水平，速度和路网偏差较大。分类器可能对分布外轨迹失效；不能仅提高分类概率来掩盖生成质量问题。直接序列选择器与审计器同架构，仍可能存在评估偏好，因此保留几何与运动指标。

先改善生成器：启动G2，在统一相对坐标、EMA与运动约束基础上，控制比较无地图、地图条件、地图条件＋道路距离损失。所有组使用同一数据、同一预算和同一验证起点。几何指标使用独立向量车道距离，不使用训练距离栅格给自己打分。

同时补充R2的224点窗口，检查时间范围变化。完整canonical数据已从原始表转换，时间/坐标数值检查一致；只有校验到齐并释放GPU后才启动。R2不同长度导致有效车辆子集变化，不能直接作因果比较。
