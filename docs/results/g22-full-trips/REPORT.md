# G22 完整行程生成
路线先于车流生成，核对 SUMO 实际出发和到达，按整场划分。训练 6,033/6,144、内部监测1,126/1,152、评价1,516/1,536 个合格完整行程。模型联合去噪时长和256段相对时间的运动，最终导出每0.25秒一个坐标并附准确到达点。实际起点与终点入口、给定路线入口均完成打包后实采。两种子×四候选共12,128条，生成时长中位183.5s、范围28.9–1,025.2s，8,470条超过127.75s。按每个评价路线固定一个完整样本审计，1,324条车／自行车通过车道图检查，192条行人通过单段人行道距离检查。到达由解码保证，行人不覆盖跨街区过街。经验时长迁移宏W1约6.50s，扩散约8.18s。四场验证不足以证明完整行程扩散的时长优势。

完整原空间 Hilbert–GAF 的原频率识别准确率25.4%、macro-F1 24.8%。整程原频率时序 CNN 75.3%／75.0%，属于诊断对照。原轨迹评分器只读时间顺序XY。旧版本的运动表征→车型实验不能代替速度模式识别，后者见G23。完整 GAF 在两个种子的四候选池上产生的行程时长 W1 为7.54/9.51秒，均匀7.80/9.57秒，不能声称确立稳定改善。同步源码和小型结果，权重与原数据不进Git。
