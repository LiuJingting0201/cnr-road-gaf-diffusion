# G33：完整道路条件扩散生成与双 GAF 反馈

2026-11-06。预定的 **14 项评价全部完成**：四个扩散模型、两个经验迁移池，以及原生模型两个种子各四种末端选择。依据为 [完整汇总](report/summary.json)、[全部指标表](report/TABLES.md)和[完成回执](evaluation-complete.json)，不是训练损失或分类分数代替生成结果。

**当前最明确的成果是：完整轨迹采用 0.25 秒物理时钟扩散后，独立 SUMO 参考上的原生加速度分布误差明显下降；GAF 已能读取类别并实际改变候选选择，但直接选分类最高分尚未带来普遍的物理质量改善。** 下一步保留 GAF，检验它在总时长固定后能否更有效地选择运动模式。

## 生成模型：有实际改善，也有具体代价

下表为五类宏平均 W1，越低越好；斜线前后为模型种子 42 / 43。

| 全候选生成方法 | 原生速度 W1（m/s） | 原生加速度 W1（m/s²） |
|---|---:|---:|
| 257 点相对时钟扩散 | 0.6794 / 0.8238 | 0.8397 / 0.8319 |
| **0.25 秒物理时钟扩散** | **0.6093 / 0.7437** | **0.1492 / 0.1575** |
| 训练侧经验运动迁移 | 0.8373 / 0.9691 | 0.3245 / 0.3588 |

原生加速度 W1 较匹配的 257 点模型下降 **82.23% / 81.07%**，较经验迁移下降 **54.03% / 56.10%**；原生速度 W1 较 257 点下降 10.32% / 9.72%。这是生成候选与独立参考的分布比较，已经超出 G32 的 oracle 重构结论。停止比例和一秒平均绝对加速度的分布误差也下降。

收益不是所有指标都同向：相对 257 点模型，最长停车 W1 从 **4.69 / 4.89 秒增至 7.75 / 7.66 秒**，p95 速度 W1 从 1.8650 / 1.8252 增至 1.9802 / 1.9495 m/s，最长巡航误差也略增。不能概括为“全部运动模式更真实”。全部十项指标及逐类支持保留于汇总，未按结果删类或删指标。

同请求候选的相对进度分离均值从 0.03434 / 0.03505 增至 0.04017 / 0.04039，未观察到该描述指标上的多样性收缩。原生模型最近训练进度 MAE 为 0.01506 / 0.01483，经验迁移约 0.00013；这只描述形状接近程度，不证明无记忆或隐私保证。三种全池方法共享训练侧时长先验，时长 W1 完全相同（48.28 / 46.39 秒），不能归功于运动扩散。

四次拟合均为 10,000 步、有效 batch 64、同一 891,969 参数网络。257 点模型实际耗时 **5.01 / 5.31 分钟**，原生模型 **25.33 / 25.49 分钟**，约为对应种子的 4.8–5.1 倍。物理分辨率改善有计算代价，等步数不是等算力；本轮没有再加训练预算寻优。模型配置与完成回执见[训练记录](../g33-training/models/)；全池质量图见[生成比较](figures/generation-quality.pdf)。

## GAF：类别可读、候选可区分，最高分仍不等于最好轨迹

两支均使用相同 925 条训练、126 条开发完整车辆轨迹，自训固定 50 轮 ResNet18。空间原 Hilbert–GASF/GADF/MTF 宏 F1 **69.80%**，速度 GAF **84.99%**；这不是组内提供的 CNN，也不是生成质量。概率可靠性、逐类支持及编码边界见[教师报告](../g33-training/TEACHERS.md)。

原生模型每种子 97 个 K=8 池，Uniform、S、V、SV 严格共享候选，两个种子各完成四项选择评价：

| 交付策略 | 原生速度 W1（m/s） | 原生加速度 W1（m/s²） | 时长 W1（s） |
|---|---:|---:|---:|
| Uniform | 0.7329 / 0.5828 | 0.1245 / 0.1597 | 57.78 / 51.59 |
| 空间 S | 0.5782 / 0.7619 | 0.1362 / 0.1500 | 58.40 / 51.49 |
| 速度 V | 1.0599 / 1.0078 | 0.1233 / 0.1314 | 74.42 / 77.68 |
| 双支 SV | 0.7214 / 0.8619 | 0.1280 / 0.1373 | 59.01 / 68.06 |

空间 S 的速度收益在两个种子间方向不同；速度 V 的原生加速度误差下降，但速度和时长误差均上升；SV 未稳定优于单支或 Uniform。因而本轮支持有条件的运动变化，尚不能声称最高类别概率普遍改善合成数据，或双支已经形成互补优势。单次交付每请求只有一条，不能把“池内多样性不可计算”填成零或解释为模式坍缩。

事后只读[机制诊断](gaf-ranking-diagnostic.json)排除了“空间图全一样，所以完全不起作用”的解释：**194 个请求×模型种子池中，193 个有 8 张不同空间图，另一个有 7 张；无编码失败回退，两支均无完全同分池。** S/V/SV 分别在 177/172/174 个池中改变 Uniform 选择，S 与 V 仅 31/194 次选择同一候选。它们对候选敏感，但不同图和不同选择并不证明排序正确，也不证明语义互补。

速度 V 将所选样本自身目标类概率的平均值从 0.766 提到 0.989，同时出现上表的物理代价。空间/速度候选概率范围均非零；问题不能只归为分类器没有响应。固定路线内的空间图差异仍可能来自采样密度和跨格跳跃，不能包装为生成了更好的新路线。194 是请求与模型种子的组合数，不是独立仿真场次。

## 下一步：固定时长检验 GAF 的运动反馈

[G34 协议](../../G34_PROTOCOL.md)已随 `ab2c501` 锁定。每个请求和模型种子重演原 Uniform 首选候选的**训练先验时长 T**，让新 K=8 池共享该 T，只改变初始运动噪声；不读取真实参考时长，也不按 GAF 分数选择 T。两个教师、扩散权重、K、DDIM 步数、四策略和评价方法均保持固定。

这检验的是：排除“通过挑快慢行程改变总时长”的自由度后，GAF 能否更好地选择停走、巡航、速度分布形状及加减速。时长偏好只是 G33 提出的待检验机制，不能据当前结果断言它解释全部负效应。**截至本报告更新，G34 为协议已锁定、实现准备状态，未报告运行完成或收益。** 它使用已分析的开发参考，不替代 G33 主表，也不是新的盲测或采样中 guidance。

## 覆盖与结论范围

- 四次模型拟合已完成；六个全池各 **776 条**候选，来自 97/100 可解码请求；八项末端策略各交付 97 条。每个全池有 752 条候选可与 94 个参考请求配对。重复方法输出不计作额外独立数据。
- 独立 SUMO 的 100 请求全部到达，97 参考通过预定检查；地图支持也为 97，但不是同一集合，**质量覆盖为 94/100**。所有地图与参考失败保留，不补样。质量按类别内请求等权、请求内候选等权汇总，完整支持数已保存。
- 数据为单个训练 pilot（925/126），参考为一个新仿真种子、同地图及公开需求模板；属于有限开发证据，没有独立场次置信区间、跨城市或未见线路泛化结论。原测试未重新用于选型。
- 生成直接输出完整带时间坐标轨迹；道路许可与连接来自共同解码器，时长来自共同先验。本轮评估的是**末端 GAF 反馈**，没有采样中引导或新下游增广结果。原始数据、模型权重与逐请求输出留在服务器。
