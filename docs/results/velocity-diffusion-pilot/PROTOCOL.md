# Generating a trajectory by integrating sampled velocity vectors

## Single-class pilot

Use completed MoST taxi trajectories with the verified 40k/1k training/development split. The two models receive identical original trip descriptors, including start and end cells, duration and average speed. Compare the original coordinate DiffTraj A and a model that generates the initial position relative to the origin cell and the 199 Cartesian velocity vectors between successive elapsed-time points. Each vector has east and north components in metres per second. Each interval spans T/199 seconds. The initial position is generated jointly with velocity. Reverse the affine transformation and sum velocity times interval duration to obtain the 200 metre-coordinate positions. Neither observed directions nor precise observed endpoints enter the sampler. There is no post-hoc endpoint correction or map snapping. Native SUMO scalar speeds cannot supply these two vector components.

Keep the released coordinate backbone, noise objective, train budget, stable optimizer, seeds (42/43) and sampler. Among 1,000 same-class development requests compare identical request and initial-noise fingerprints across both representations. Baselines are the existing matched 50-epoch coordinate checkpoints, sampled again on the identical cohort. Verify encode/decode on observed trips independently of generative quality. Report the four DiffTraj metrics plus physical speed and acceleration distributions, length error, start and destination cell hit rates, position errors in metres and whole-trip displacement-vector error. Compare generated map examples in fixed request order. A different path between the same endpoints can be valid.

This stage assesses whether velocity-domain diffusion simultaneously produces plausible motion and useful spatial trajectories. A speed improvement accompanied by a major loss of destination accuracy or a collapsed spatial distribution does not justify a labelled scale-up. A single-class fit cannot measure a vehicle-label effect. Frozen test data stay reserved.
