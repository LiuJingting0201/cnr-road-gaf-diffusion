# Frozen independent taxi evaluation cohort

Run `fresh_taxi_holdout.py` in an empty experiment folder with the colocated `make_balanced_trips.py` and SUMO environment used for the original 10k release. This generation step reads no model weights or quality scores and uses CPU only. All five classes have 100 demand requests per episode. Only eligible taxis enter the evaluation set. Network, route sampling, episode duration, slot allocation, 1-second native sampling, arrival check and the 120-position rule follow the original generator. Each trip spans observed departure through its final pre-arrival SUMO sample.

The first fresh episode is 3,310,000. Its ID differs from the original test start by exactly 2,000 multiples of 1,440. This preserves the artificial time-of-day convention used in the previous holdout while drawing independent demand and simulator seeds. Accepted rows follow episode and original lexicographic vehicle order, mirroring the original release. Exact duplicated 200-position traces, compared before normalization, are excluded across all three prior partitions of both previous releases and within this cohort.

Server folder: `/workspace/cnr-experiments/taxi-debug-fresh-01`. `native.npz` stores native simulation time in seconds, x and y in metres and SUMO-reported speed in m/s, with per-trip lengths and vehicle IDs. `observations.npz` stores the same positions rounded to centimetres as coordinate differences plus lengths, assigned start times, true durations and IDs. Every row is evaluation-only. When applying a model, reuse its training split's coordinate and numeric-header normalization and cell limits. Running `porto.py prepare` directly on this evaluation-only pack would have no training population.

The same road network, demand-selection policy and synthetic fleet types apply to both development and this evaluation cohort. The cohort audits unseen simulated trips under the same scenario. For a change of native sampling rate, transform the original time-stamped native tracks; use the same predeclared eligibility logic for train and held-out observations.

For time-header variants, the true (unshifted) SUMO departure is in the first row of each native trip and equals `observations['start'] - (episode_seed % 1440) * 60`. The legacy `start` is retained for exact comparison. The reference pack also contains `simulation_start` explicitly. The true local episode clock starts at zero. SUMO does not observe actual local civil time in this demand construction.

To generate the separate observed-reference set in another empty folder run the same script with `--reference` after the test pack is complete. The 3,000 reference trips use seeds beginning at 3,454,000. Filtering and demand generation are unchanged. Deduplication checks include the 1,000 sealed evaluation trips. This reference supports descriptive real-versus-real comparisons at equal sample sizes. Separate model selection and final scoring decisions are recorded by the main experiment.
