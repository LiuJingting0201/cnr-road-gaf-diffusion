## 如何用于接下来的生成实验

生成器只能读取已冻结请求与地图，不读取参考轨迹的真实未来路径、时长或运动序列。97 条参考用于与生成数据比较；所有策略仍面对原先 100 个请求，SUMO 数据不合格与生成/解码失败分别统计。公交公共模板未按路线强制隔离；非公交 parent 已按现有规则隔离，但道路与路线仍可能重复。该单场是同地图、同公共需求族的受控新参考，不能据新 ID 声称未见路线或城市泛化，也不能估计跨仿真场次的置信区间。

此后主表应比较基础扩散、空间 GAF、速度 GAF、双 GAF 对这些独立参考的运动质量与多样性；本队列不再追加分类诊断或地图可构造性筛选。
