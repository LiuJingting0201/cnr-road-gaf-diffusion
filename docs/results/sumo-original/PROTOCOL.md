# Original conditional DiffTraj on supplied SUMO observations
Source: midimost_with_class2.csv. Exclude pedestrian rows to define a vehicle population. The only stored model inputs originate from vehicle IDs, planar metre coordinates and simulation seconds. No vehicle-class or simulator-speed channel. Sort each vehicle record by time, collapse duplicate timestamps, require 120 native observations, finite coordinates, movement, and no gap above 2 s. Encode positions at centimetre precision. At the median 0.25 s cadence the cutoff spans only 29.75 seconds. Tracks correspond to the observed simulation window.

Use the original coordinate Guide_UNet, eight header attributes, 200 interpolated positions, 500 noise levels, guidance scale 3, noise MSE, fixed-rate AdamW (0.0002), batch 1024, 200 epochs and the final checkpoint. Use 100 deterministic reverse steps in eval mode. DDP uses two L20 GPUs per seed. The released script tracks EMA but saves ordinary network weights. Departure bin is derived from simulation seconds. Length and mean speed use Euclidean distances in metres. These choices adapt the release to a planar simulator and user-held data. The vehicle hash split, sample size, grid extent, 20 training-quantile length bins and top-20 hotspot convention are local. Score every reserved vehicle once, plus independent real development versus real reserve at equal counts. Identical seeds for sampling between the two training fits. Because the corpus is small, the original batch and epoch budget yields few optimizer updates. This experiment intentionally preserves that budget. No extension or alternative budget is trained.
