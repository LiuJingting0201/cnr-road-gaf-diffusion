# G32：固定物理时钟修复长程平滑，但1秒不足以保留原生运动

2026-11-06，**三臂表示检查已完成，全部1644段保留，生成就绪仍为false。** 本轮只重构已有G31行程，没有训练模型、生成新仿真或修改论文。协议先于真实执行固定，见[预先固定协议](../../G32_PROTOCOL.md)；机器聚合结果见[clock.json](clock.json)。

主要结论：257个相对时间控制点会随行程变长而失去时间分辨率。1秒物理时钟显著减轻这一问题，但它在原生0.25秒上仍平滑秒内变化，且总体原生加速度误差比旧表示略大。0.25秒变长控制保留运动细节明显更好，因此下一版模型建议以**0.25秒物理时钟的完整变长序列**为目标，1秒指标保留为较低频的运动摘要；这是一项表示选择建议，不是已验证的生成改进。

## 1 范围、重放与指标

输入与G31完全相同：1644个完整事件/观察段、1592个parent，六类、train/val分区以及所有时长层保持不变。没有常量段，3个不足5秒的段全部保留。观测时长与事件时长分开，不猜补事件终点的未知坐标。同一parent多段和同场交通不视为独立样本；此处报告描述性统计，不计算伪独立置信区间。

三臂共享真实目标构造的2049点等弧长空间路径（float64），归一化进度均为float32；唯一预定变化是时间控制：257个等相对时间点、每1秒一个点、每0.25秒一个点。物理时钟显式保留最后不足整秒区间，以实际秒数插值，不重新等距摊回相对时间，也不拼接硬分块。三臂均在原始0.25秒观察时刻输出。

运行核验了源数据与源码哈希、逐段旧臂坐标，以及旧臂全部G31聚合结果；全部通过，未覆盖旧结果。各臂输出支持相同：1644段都有几何与原生速度/加速度；1秒速度/加速度各1643段支持，四秒速度变化1641段支持。最短0.75秒段保留在几何和原生口径中。

两种运动时钟须分清：

- **主口径**沿用G31：由坐标累计弧长在整数秒上的增量得到1秒速度，再作差得到加速度，保留原十项物理量及停止/巡航状态。
- **辅助口径**在原生0.25秒上，以相邻坐标位移除实际时间间隔得到速度，再以速度差除区间中点时间差得到加速度。它不是SUMO输出的`speed`。辅助口径专门检查1秒主口径看不见的秒内误差。

下列MAE先逐段对齐时间序列计算，再按段汇总。p95是**逐段MAE或逐段最大误差的95分位**，不是把所有时间点混成一个分布。长段不会仅因采样点多获得更高权重。

## 2 总体：1秒指标改善不等于原生运动恢复

| 指标 | 257相对时间 | 1 s物理时间 | 0.25 s原生时间 |
|---|---:|---:|---:|
| 位置MAE均值 m | 0.1784 | 0.0581 | 0.0144 |
| 1 s速度MAE均值 m/s | 0.1647 | 0.0101 | 0.0091 |
| 1 s加速度MAE均值 m/s² | 0.2433 | 0.0125 | 0.0109 |
| 0.25 s速度MAE均值 m/s | 0.2614 | 0.1960 | 0.0093 |
| 0.25 s速度MAE p95 m/s | 0.6071 | 0.4567 | 0.0263 |
| 0.25 s加速度MAE均值 m/s² | 1.0514 | 1.1542 | 0.0314 |
| 0.25 s加速度MAE p95 m/s² | 2.4644 | 2.6716 | 0.0847 |

1秒主速度/加速度MAE均值降至0.0101 m/s和0.0125 m/s²，但原生加速度MAE从1.0514升至1.1542 m/s²，配对平均差为+0.1028 m/s²。1秒线性进度只能表示各秒内的平均运动，控制点间速度趋于常数、转折聚集在秒边界；这能解释为何整数秒摘要很好，却不保证0.25秒加速度更接近原观察。这里只是与插值结构一致的解释，未把所有残差都归给这一机制。

0.25秒臂相对1秒臂的原生速度、加速度MAE配对平均差分别为−0.1868 m/s、−1.1228 m/s²，配对差的最大值仍分别为−0.0255、−0.1569：在此固定队列的全部1644段上，这两项MAE均更低。与之相比，1秒主速度MAE只再降低0.0010 m/s，说明仅看整数秒指标会低估剩余秒内损失。这不等于所有物理端点、所有时刻或所有未来数据上都严格更好。

## 3 类别差异：长公交获益，短行程可能被1秒降采样

各单元按“257 / 1 s / 0.25 s”顺序给出逐段MAE均值。

| 公交 | 93 | 0.4237 / 0.0066 / 0.0066 | 0.4847 / 0.1343 / 0.0067 | 0.8300 / 0.7847 / 0.0207 |
| 摩托车 | 269 | 0.2478 / 0.0150 / 0.0144 | 0.4660 / 0.4233 / 0.0148 | 2.2946 / 2.5106 / 0.0516 |
| 私家车 | 507 | 0.2668 / 0.0155 / 0.0154 | 0.3587 / 0.1963 / 0.0159 | 1.1365 / 1.1337 / 0.0513 |
| 自行车 | 106 | 0.0766 / 0.0072 / 0.0061 | 0.1757 / 0.1781 / 0.0062 | 1.0039 / 1.0705 / 0.0247 |
| 出租车/网约车 | 76 | 0.0930 / 0.0072 / 0.0070 | 0.2042 / 0.2539 / 0.0070 | 1.0648 / 1.4935 / 0.0242 |

公交1秒速度MAE从0.4237降至0.0066 m/s，巡航状态不一致从21.06%降至0.29%；但同一1秒表示的原生加速度MAE仍为0.7847 m/s²，0.25秒臂则为0.0207。行人、出租车/网约车的1秒表示在原生速度和加速度上均劣于257点表示；自行车原生误差也略增，摩托车原生加速度增大。不能只展示公交而宣称1秒普遍改善所有类的动力学。

类别与时长不是正交因素：公交中位观察1054.5秒，旧控制间隔约4.12秒；行人中位161秒，旧间隔约0.63秒。1秒对前者加密，对后者反而变粗。这是按物理时间定义目标的理由，而不是通过车型分别挑最优网格的理由。本轮没有进行这种选型。

## 6 代价：更长序列，不是等算力胜利

| 控制序列 | 点数均值 | 中位数 | p95 | 最大 | 平均点数/257 |
|---|---:|---:|---:|---:|---:|
| 257相对时间 | 257.0 | 257.0 | 257.0 | 257 | 1.00 |
| 1 s物理时间 | 429.6 | 369.5 | 944.0 | 2356 | 1.67 |
| 0.25 s原生时间 | 1713.8 | 1473.0 | 3771.7 | 9419 | 6.67 |

公交0.25秒序列的中位数4219点，最长9419点；其1秒表示为1056/2356点。总体0.25秒约为1秒的4倍控制点、旧257点的6.67倍，最长约旧表示的36.65倍。点数是表示容量，不是实测训练耗时/显存倍数；没有模型训练，不能声称四张GPU上实际快慢。短行程原生序列反而可比257点少。

## 7 下一模型建议与GAF主线

1. **以0.25秒变长物理时钟作为完整行程目标，保留1秒摘要作辅助约束与评价。** 不再把任意时长压成257个等相对时间点，也不把1秒线性插值的0.25秒输出称作原生高频生成。这里选择的是既有三臂中的原生表示，不增加网格扫描。
2. **先做有限训练适配。** 沿用连续单调进度/非负增量及整程时长建模，按长度分桶、padding mask和真实时间条件处理完整序列；使用可扩展的时序卷积/层级计算控制长度成本，跨尺度保持同一条连续进度，不能各硬块独立归一化再拼接。它能否学会长公交的停走结构仍需小规模有边界的训练验证，不能由本重构结果代替。
3. **地图条件门槛继续单列。** 同时完成事前路线/许可车道/站点及换道的解码接口；本次真实目标空间路径绝不能替换成正式生成条件。原生尾部残差也提示需核验空间离散与地图解码的误差，不能仅因时间表示改善就宣布地图条件可用。G32路线构造器的构造测试亦不等于真实请求的完整覆盖率。
4. **GAF作用按层检验。** 在G30已校正的原生需求域里，空间Hilbert–GAF可检验路线/空间选择的类别结构，速度GAF检验相同路线内的车型运动模式；均保留无GAF、正确配对/打乱配对以及同预算末端筛选对照，评价全候选物理质量、多样性与独立类别读出。没有组内CNN权重，读取器仍明确为自训。先确保目标运动没有被输入表示抹平，再检验GAF是否提供生成增量。

以上是下一协议的建议，不是已启动训练或新增正面论文结论。G32不证明所有历史GAF失败都源于257点，不证明空间分类恢复自动转化成引导收益，也不证明0.25秒精度值得所有未来任务付出相同计算成本。正式结论仍需不含真实未来路径的生成、独立新车流与完整失败分母。
