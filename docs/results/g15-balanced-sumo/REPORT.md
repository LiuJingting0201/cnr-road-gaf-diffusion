# Monaco MoST 八类均衡 SUMO 轨迹数据

## 下载内容

- `balanced-trajectories.zip` 内含 train.csv、validation.csv、holdout.csv 和 manifest.json。
- `road-annotations.zip` 的三个同名 CSV 提供逐段 SUMO 原生车道或道路 ID，以车辆或行人 ID 加分区关联。区间采用从零开始的左闭右开下标。
- `most.net.xml.gz` 是上述仿真的 MoST 路网，解压后 SHA256 与轨迹清单一致，可在 sumo-gui 中打开。
- `complete.json`、`road-complete.json` 是两个数据包的校验收据。两个包记录同一批参与者。

## 规模

8 个类别：行人、公交车、摩托车、私家车、自行车、出租车、货车、配送车。每类各 8,000 条训练、1,000 条验证、1,000 条留出轨迹。每个参与者只留一段 512 点轨迹，0.25 s 一个位置，覆盖 127.75 s。80,000 个 ID，共 40,960,000 条位置记录。

| 分区 | 仿真批次 | 请求 ID | 合格 ID | 均衡后 ID | 位置数 |
| ---- | -------: | ------: | ------: | -------: | -----: |
| train | 86 | 68,800 | 68,094 | 64,000 | 32,768,000 |
| validation | 11 | 8,800 | 8,723 | 8,000 | 4,096,000 |
| holdout | 11 | 8,800 | 8,719 | 8,000 | 4,096,000 |

## 坐标与来源

使用 Eclipse SUMO 1.28.0、同一张 Monaco MoST 路网、独立的需求和仿真种子。五列为 `time,id,x,y,type`。time 是各场仿真本地秒数，x、y 是路网米制坐标，参与者标签保留原始拼写 `bycicle`。公交与出租车使用 SUMO 的默认车辆类别和自定 OD，无公交时刻表或叫车订单。行人用 SUMO person/walk；禁止把不可达人行道用直线连起来。各类数量按研究配额设置，不代表摩纳哥真实出行比例。

每个候选窗口检查连续性、原生道路标识、坐标有限、移动距离和位置跳变，并在所有交付分区中排除重复坐标序列。归属以完整仿真场次决定。同一张地图上的道路可能在不同分区中再次出现。车道/道路标注是已走过的未来，训练可用作监督，盲评时不可作为生成器输入。新数据使用模拟器原生道路标识，原论文的严格地图重建与五类扩散训练另有协议。论文中既有模型的准确性不能据此直接外推至新增类别。

复现脚本和固定配额见私有研究分支的 docs/G15_DATA.md。原始 CNR 表格与扩散模型生成样本未混入该包。
