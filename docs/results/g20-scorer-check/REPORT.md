# G20：八类识别器的同 ID 运动特征对照

冻结 G19 的 8,192 个拟合 ID、1,024 个内部监测 ID 和 175 个 G15 开发参考请求。比较原 Hilbert–GAF ResNet18 与一次固定的运动特征基线。后者是 200 棵 ExtraTrees，最小叶大小 5，使用每秒速度和加速度的分位数、近停比例、四秒速度变化等 19 个标量。无坐标位置、道路 ID、车辆 ID 特征或测试使用。G19 的开发结果在设计本次诊断时已知，因此这是同开发集诊断，不是新增盲测。

| 同一批 SUMO 开发轨迹 | 八类准确率 | 宏 F1 | 公交识别 | 货车识别 |
|---|---:|---:|---:|---:|
| G19 原编码 + 自训 CNN | 48/175（27.4%） | 27.0% | 0/22 | 2/22 |
| 速度／加速度统计 + ExtraTrees | 133/175（76.0%） | 75.4% | 21/22 | 19/22 |

八类 CNN 的48个正确预测有31个属于行人和自行车；其余六类合计17/132。固定物理特征基线在私家车、出租车、配送车之间仍有混淆。这个对照证明当前 SUMO 窗口含有可识别的类别信息，但同时更换了表示和分类算法，不能单独归因于编码丢失、CNN 容量或训练不足。数据是 SUMO 类别默认参数和受控需求下的运动，不外推现实交通。

G19 已独立检验候选筛选；冻结 CNN 的选择在 G14 道路组没有带来已确立的弯速差或巡航误差收益。当前 CNN 不适合充当生成类别的裁判。速度基线也只在此处用于识别诊断；未据该基线的识别率推断候选选择效果。将来若研究原 GAF 的增量，需比较运动特征单独与运动特征加 GAF，并在新开发车流上评价生成轨迹。
