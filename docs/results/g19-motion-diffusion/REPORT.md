# G19｜八类路网条件扩散与 Hilbert–GAF 候选反馈
沿用 G17 两个八类种子，四张 L20 各自完成 10,000 次额外扩散更新。两组共享 63,717 个满足 64 m 资格的 G15 训练窗口、随机种子、类别采样、优化器、外部路径和每起点四候选。普通组学习物理沿路位移；道路组利用训练数据标定的局部曲率／道路限速响应修正空间坐标，在该坐标上学习扩散运动，再反算物理距离并解码。候选规划只见起点、类别与地图。训练看 SUMO 原生车道限速，推理使用最近的兼容车道作限速近似；没有观测信号相位、车头时距或公交停站事件。两个因素共同改变，不能单独归因于限速或曲率。原 CNR 测试及 G15 预留集未使用。

指标以请求为单位，先算各类生成与 SUMO 参考的均值之差的绝对值，再跨类平均。弯道指标为轨迹内弯段减直段的速度差；巡航指标为最长连续平稳运动时长，1秒速度变化小于0.5 m/s且当秒速度不小于0.3 m/s。以下为道路模型相对同预算普通模型。

| 验证域 | 弯道速度差误差（m/s） | 最长平稳行驶时长误差（s） | 行程 W1（m） |
|---|---:|---:|---:|
| G14 五类、8场、120 起点 | 1.77→0.42 | 18.23→37.55 | 160.7→174.0 |
| G15 八类、11场、175 起点 | 1.78→0.45 | 7.57→23.97 | 77.9→87.7 |

G14 主差 −1.35 m/s [−1.63,−0.99]；时长误差差 +19.32 s [+18.02,+20.33]。G14 公交参考弯段比直段慢2.40 m/s，普通扩散慢0.37，道路扩散慢2.76。G15 对应为3.42、0.35和3.62。区间按整场配对重采样，条件于两种子；G14 是来自独立车流的开发域，已在 G18 诊断中查看，不能称作新盲测。G14 道路组960条候选均通过有向车道审计且无路径耗尽；G15 道路组1,232条车辆／自行车通过图审计，168条行人通过单段人行道距离检查，4条路径耗尽。不同规划路径上的关联不能用于宣称在同一交通灯前做出了正确决策。

## GAF 对合成质量的影响
从自训 G12 权重初始化八输出 ResNet18，保留原 Hilbert 编码、GASF/GADF/MTF 和既有训练范围。每类1,024条训练、128条内部监测，固定5轮；均为 G15 训练侧 ID。监测准确率32.9%；G15 的175个独立开发请求均成功编码，准确率27.4%、macro-F1 27.0%。这些是短窗自训分类结果，不是组内 CNN 或论文全轨迹精度。

G14 道路组：960条候选均可编码。固定均匀槽位和GAF选中轨迹在180/240个池中不同。GAF−均匀的弯速差误差 +0.02 m/s [−0.17,+0.22]，最长平稳段误差 +0.56 s [−1.19,+2.55]。G15 的两项差分别为 −0.03 m/s [−0.17,+0.13]、+0.27 s [−0.86,+1.56]。保留全部候选、选择标签与路径耗尽标记。GAF 可作为工作流中的可选反馈，对这两项物理模式没有确立改善。模型包已实际执行外部起点＋类别采样，输出四条轨迹及 GAF 选择 ID。

## 复现
在隔离目录提供上一轮 G17 的 src、.venv、g10-env、data，以及父目录已有的 G12 CNN 与原编码 vendor。将 G16/G17 公共脚本加入 PYTHONPATH；另将 ../scripts 和 ../vendor/original_cnr/src 加入。分别运行 g19_field.py 和 g19_gaf.py，然后运行 g19_run.sh。训练／评分就绪后运行 g19_eval.py results、g19_eval.py graph、g19_scorer_check.py，最后运行 g19_deliver.py。输出与指标在 g19-data/。模型权重和原始数据不在 Git 中。
