# G34：固定行程时长后，GAF能否改善轨迹运动？

2026-11-06。两个模型种子、两个全候选池和八项末端选择评价均已完成。结果支持一个有限的结论：**同一路线、车型和总时长下，速度GAF末端选择仍能改变运动形状；在本次两个种子的五类宏平均中，它同时降低了原生加速度分布误差、最长停车、停止比例和停走频率误差，但恶化了最长巡航和高分位速度误差。** 这不是全面质量提升，也不是新盲测、采样中guidance或双GAF互补已经成立的证明。

## 1. 本轮改变了什么

G33的速度GAF最高类别分选择会重选总时长：时长W1从Uniform的57.78/51.59秒增至74.42/77.68秒。G34依据这一开发结果提出机制对照，并在新候选生成前固定[协议](../../G34_PROTOCOL.md)。沿用G33的100个事前请求、地图、两个原生0.25秒扩散模型、两位五类别教师、K=8及DDIM=100，没有新训练、重拟合先验、调整评分强度或重跑仿真。

对每个请求和模型种子，用原Uniform规则（seed33073的请求排列首slot）选定一个候选ID，再用该ID及模型种子重演**训练侧**时长先验，得到唯一T。八个候选均以此T重新采样运动，各自仍使用原候选ID派生的运动噪声key。没有读取真实参考时长，没有按GAF分数挑T。T在同一个池内固定，在不同请求和模型种子间仍可不同。

这不是从原G33池筛出时长相同的子集：非Uniform候选可能改变序列长度，需要重新生成。保留同一噪声key不等于不同长度的噪声张量逐元素完全相同；只有Uniform的时间维度、噪声与结果全部相同，已作逐点核验。因而G34回答的是“限制时长重选这一自由度后的反馈表现”，不能据此把G33的全部误差归因于时长。

## 2. 完成、覆盖与实现核验

- 每种子仍以100请求为分母，地图支持97、合格SUMO参考97，交集94。配对类别数为公交19、摩托18、私家车19、自行车19、出租车19。三个地图失败和三个参考失败没有补样。
- 每种子生成97×8=776候选，全部成功；752候选进入全池配对评价。Uniform/S/V/SV各交付97条，其中94条用于配对质量。两种子合计1,552候选、776条被选择输出，不能把它们当独立仿真场次。
- 两种子各97个请求的新旧Uniform轨迹时间和坐标逐元素完全相同，最大绝对误差为0。全部776候选及四种选择的T均等于该请求原Uniform的T。实际数组检查在服务器原地完成；本报告独立复核保存的检查回执，没有下载原数组。
- 本地进一步核对queue→summary哈希、池与选择的来源哈希，重算10项评价的120个五类宏平均值，与JSON和CSV一致。所有新评价都使用原G33地图、训练数据和开发参考。
- 空间/速度编码失败与共同Uniform回退均为0。空间图并未普遍相同：每种子96个池有8张不同图，另一个池分别有7张、5张。

回执见[summary.json](attempt2/report/summary.json)、[queue-complete.json](attempt2/queue-complete.json)及[完整CSV](attempt2/report/macro.csv)。逐类全部数值与支持数见[per-class.csv](attempt2/report/per-class.csv)。回执与数据文件的哈希追踪保留在服务器；Git只保存聚合数值和小型回执。

## 5. 失败与重试

第一次有限队列的两个种子分别在0.00538/0.00558秒由源码哈希保护中止，错误为`G33 model implementation changed`，尚未加载模型权重或生成轨迹。原因是`sample`经过`@torch.no_grad`包装，`inspect.getsourcefile(sample)`定位到PyTorch包装器，而非`g33_model.py`。这是新G34代码的来源定位错误，不是G33权重变化或训练失败。

修复仅将G34四处源码定位改为`MotionDenoiser`的源文件，并新增与`inspect.unwrap(sample)`同源的构造检查。真实配置和旧基线回执均核对模型源码SHA256为`2fba15667ae2b788ec498e226f10a058e4d3f3efe236d0eced44c32de3b97075`，见[只读预检](preflight-attempt2.json)。没有修改G33科学模块、评分器、模型或实验参数。旧失败留在[attempt1](attempt1/)，新队列另写`g34-data-attempt2`，见[attempt2启动回执](attempt2/queue-started.json)。

## 6. 论文能写到哪里

本轮给出的是**反馈应与其能改变的生成自由度相匹配**的开发证据：不让车型分类置信度重新决定行程总时长后，速度GAF仍可在固定T的运动候选中找到部分更接近SUMO参考的加减速和停走分布。这使GAF的作用落在实际生成结果上，而不只是分类准确率；同时保留了巡航和高速尾部的代价。

证据范围限于已经查看过的G33单场开发参考、同一地图和公共路线模板、单pilot训练数据及两个固定模型种子。协议虽在G34新候选前锁定，研究问题由G33结果启发，因此不是新盲测。没有置信区间，没有新路线/城市泛化，没有碰撞或信号遵守保证；类别宏平均改善不代表每类一致。

本轮仍是完整扩散轨迹的**末端同池选择**，没有在去噪中施加梯度，也没有新增真实留出增广实验。没有同信息非GAF评分器对照，不能分离“角场编码本身优于其他表征”的效果。G33原结果与G34机制对照须并列呈现，不用G34替换原表。两次生成与八次选择评价完成后，本轮按协议结束，不追加时长规则、阈值、权重或种子扫描。
