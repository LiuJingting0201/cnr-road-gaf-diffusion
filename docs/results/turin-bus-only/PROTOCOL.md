# Turin bus-only external validation

Use all 3,262 fleet-consistent, terminal-covered bus trip candidates from the single service day. Vehicle-disjoint hash split as in Porto. Fit two independent original coordinate DiffTraj models, both retaining all eight trip attributes; no class embedding, tram data or speed auxiliary loss. Use measured elapsed duration and Europe/Rome departure time. Interpolate by sequence index as in Porto, restore original point count for scoring. Each seed gets 200 epochs, global batch 1,024, gradient clipping and cosine annealing, best development noise-loss checkpoint. Use all unique reserved requests once. Score density JS, OD JS, training-quantile length JS and full-grid top-20 F1; also record kilometre W1 and the original training-core density sensitivity. Real/real control compares equal-sized disjoint development and reserved trips. These differ in vehicle composition.

Compare to both long-trip Porto seeds under the historical per-training-set full grid. Porto had 46,470 training journeys and 3,000 evaluation journeys and a 120-point minimum. Turin uses terminal and service coverage on about one-minute GPS and has a smaller sample and update budget at equal epoch count. Its grid represents Turin rather than Porto. This tests transfer of a recipe, not identical population difficulty or new-day performance.
