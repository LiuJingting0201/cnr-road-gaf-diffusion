# G16｜扩容后的扩散轨迹合成，3,000 步预算
两个种子×四个训练臂均完成，所有样本使用共同起点、相同规划器和四个固定噪声候选。A=423 个合格 CNR 原训练对象；D=原始加固定 425 个 SUMO 训练对象；B=原始加全部可用五类 SUMO 训练对象；C=扩展为八类的混合模型。三种混合模型在原五类内部使用相同 50:50 数据来源配比。新五类训练池 39,816 条（各类以 data-complete.json 为准），八类 63,717 条。路线前 64 米作为网络条件，全程按外部路线解码。因 64 米门槛排除了部分慢轨迹。

G15 上 B−A 为 +76.7 m [39.6,105.1]，B−D 为 −20.2 m [−29.6,−8.3]；区间按整场仿真配对重采样，条件于两个模型种子。平均绝对加速度分布误差 B−A 为 −0.145 m/s² [−0.218,−0.066]。固定时长下平均速度与行程线性相关，不作为独立佐证。开发数据结果不外推到测试。没有统一增益，不能声称加新数据总有帮助。原五类在每个 A/B/D 臂的 880 个样本全通过车辆图审计。

八类模型在 G15 验证起点生成 1,400 条轨迹：七类车辆 1,232 条通过车辆图检查，168 条行人轨迹在规定人行道的 2.01 米范围内。共 45 次耗尽规划路径，其中 28 次来自行人。行人只有 21 个合格起点，并有 301 个候选起点在达到配额前被拒。车辆图审计、行人的单段几何检查不能合并解释为完整八类拓扑验证。模型与推理示例包采用预定的种子42，保留全部候选。GAF 在本项数据扩容比较中关闭。
