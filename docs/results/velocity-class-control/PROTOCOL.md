# Does a class-conditioned velocity diffusion model generate class-specific motion?

Train on correctly labelled SUMO bicycle, bus, motorcycle, passenger-car and taxi trips. Each of the five classes supplies 40,000 training examples. Compare a shared DiffTraj generating Cartesian velocity vectors to a shared DiffTraj generating coordinates. Use identical splits, trip headers (including trip-average speed), vehicle embeddings, seeds 42/43, model architecture, noise schedule, clipping, cosine decay, batch 205 and 10 epochs. This gives 9,760 updates per fit. The coordinate control is trained from scratch at this budget. The speed representation reuses the taxi encoding: one generated two-dimensional offset from the centre of the requested start cell and 199 interval velocities, integrated at T/199. A single velocity normalization is fitted across labelled training trips. Inference does not use the true initial position, destination, bearing, trajectory or velocity.

The primary investigation concerns information from the class label conditional on the full original request, separately from marginal motion quality. With fixed request and initial noise, assess direct labels and a label sampled from 32 similar training headers with no access to the validation label. Use one fixed header-only label draw across arms and seeds. Within the 3,000 validation rows (600 per class), compare all ten unordered class pairs on common support. Match similar trip requests by the previously used rule: all five continuous standardized descriptors within 0.75, cyclic time of departure within three hours and each origin/destination cell axis within two grid cells. Pairwise differences of observed trips with similar but non-identical headers are an observational comparator. Generate each shared header with both target labels under the same noise. A label effect requires a difference at a fixed header, and useful control requires the shift to approach the observed signed class contrast. Compare these contrasts between representations; improved marginal speed W1 alone cannot establish control.

Report speed and acceleration W1 by class, macro averages, spatial distribution metrics and destination-cell fulfilment. Report all common-support counts and note sparse comparisons. For an aggregate contrast diagnostic, use pairs with at least 30 matched pairs, and report the gap between estimated and observed differences per feature relative to a zero-label-effect predictor. These development comparisons do not test cross-network transfer. Preserve existing endpoint drift as a separate quality outcome; no endpoint correction or station-based guidance.
