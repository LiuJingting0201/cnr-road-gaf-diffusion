# G23：同一条完整轨迹的空间图与速度图，哪种反馈对生成有用？

**两种图、两种任务。** 空间分支对有时间顺序的 XY 求 Hilbert 序列，再做原 GASF/GADF/MTF，由冻结 CNN 预测参与者。它不读取显式速度或加速度特征。速度分支先由相邻坐标及实际时间差获得速度；按一秒汇总，覆盖整趟行程，再重采样为128个相对时间位置，采用所有轨迹共用的0–35 m/s幅度标尺构造速度 GASF/GADF 和基于速度分箱的 MTF。这个新 CNN 的标签仅是速度模式。它不接收参与者标签或位置。数学变换不依赖 CNN；CNN 是随后可选的读图器。

本次用训练集均速三分位（8.58、11.08 m/s）定义低、中、高，在每个速度段用训练中四秒速度变化的中位数分较平稳／较波动，合计六种。给定车型与预先规划路线长度，从同类64条相近长度训练行程的模式分布抽一个目标。模式与类别有关，但不一一对应。目标抽样不看评估参考。例：新车流中公交376条覆盖五种模式，行人384条均属低速较平稳。只适用于本次受控需求。

**对照。** 两个冻结整程扩散种子，8场新 SUMO 车流，共3,021个已到达请求、24,168条候选。每次从同一组四条中交付一条。轨迹 GAF 按目标类别评分，速度 GAF 按目标运动模式评分。包含均匀选择、不区分类别的速度先验、等权秩组合、直接用速度规则匹配的对照。独立参考只在选好后用于计量。空间读图器八类识别25.1%，速度读图器六模式识别82.9%；两者任务不同，不能用这两个数判定哪种反馈更有用。

| 选择策略 | 最长平稳行驶时长 W1 (s) | 总时长 W1 (s) | 四秒速度变化 W1 (m/s) | 各类模式分布 TV |
|---|---:|---:|---:|---:|
| 均匀 | 8.23 | 8.40 | .171 | .071 |
| 轨迹 GAF | 8.07 | 7.52 | .159 | .067 |
| 速度 GAF（按车型抽模式） | 8.59 | 8.72 | .149 | .074 |
| 速度 GAF（忽略车型抽模式） | 8.28 | 8.22 | .166 | .059 |
| 两分支等权秩组合 | 8.53 | 8.25 | .153 | .067 |
| 直接按数值模式匹配 | 9.41 | 9.79 | .151 | .084 |

越小越好，先按类再宏平均。轨迹 GAF 相对均匀的总时长 W1 降0.88s（整场配对95%区间：降0.22–1.13s），相对按车型抽模式的速度 GAF 降1.21s（降0.44–1.51s）。两者在最长平稳段的差异区间跨零。速度 GAF 相对均匀改善四秒速度变化 W1 约0.022 m/s（改善0.006–0.039）；直接与轨迹 GAF 比较该项的区间仍含零。忽略车型的速度先验也没有在两个主指标上显著更差，因此当前抽样规则尚未证实类别先验带来额外收益。区间条件于既有模型、四候选预算及同地图仿真需求，多个指标未作家族校正。该结果属于采样后筛选，不是反向扩散中的梯度引导。不同目标和读图器也意味着策略差异不能被归因于 GAF 数学形式本身。
