# 同一路径上的类别运动与原 GAF 采样引导

本报告属于正式测试结束后的开发研究。用已归档的训练权重和开发请求；旧正式测试未用于本轮。三组实验分别识别类别输入、GAF 对运动的敏感度和引导策略的作用。

## 1. 冻结路径，只切换模型类别

从 33 个开发请求中的公交/私家车请求取首条已规划路径，各 8 条。16 条路径均通过两种类别的完整道路检查。对每条固定道路、每个扩散种子采用相同起点和 8 份成对噪声，各生成公交和私家车。三种子共 768 条均通过 5m 有向图检查且无路径耗尽。该实验不使用 GAF 选择。

|指标|公交标签|私家车标签|公交减私家车，按整条路径配对的 95% 区间|
|---|---:|---:|---:|
|行程，m|984.3|1,330.4|−346.1 [−469.3, −212.7]|
|速度低于 0.1 m/s 的时间比例|23.83%|5.25%|+18.59 个百分点 [11.89, 25.34]|
|独立 TCN 的公交概率|0.444|0.230|+0.214 [0.100, 0.352]|

行程差按模型分别为 −319/−375/−344m。源类别分层、16 条路径配对 bootstrap 2,000 次；seed42 是探索，另两种子是相同车辆上的复核。这里识别了已训练网络的类别响应；观测车辆不是反事实真值，不能推广至所有类别、路网或真实公交站行为。

## 2. 固定几何、端点与行程，只改变时序

33 个开发请求各取 seed42 的第一条候选，分别施加 −0.12/0/+0.12 的单调时间扰动。全部 99 个时序变体可编码，33 组都能改变 GAF 图像。目标类概率的组内极差中位数（公交/摩托/私家车/自行车/出租）为 0.432/0.341/0.184/0.700/0.966。选出 GAF 分数最高的时序，相对组内平均的目标概率提高 0.257，独立 TCN 的目标类概率变化 −0.004，与观测同类开发轨迹的速度 W1 平均增加 0.289 m/s。这个指标按单请求计算，区别于下表类别宏平均的分布误差。

## 3. 在去噪中进行一次 GAF 引导

在 100 步中的第 76 次更新，根据预测干净轨迹的原 Hilbert–GASF/GADF/MTF 图像，用自训 CNN 的目标概率无梯度重采样。用独立随机 DDIM 更新继续去噪；轻度随机性在所有方法中等同。33 请求，每请求同一路径、8 条粒子，三个生成器。独立 TCN 审计用两个与选择器分开的权重。每方法在逻辑上均为每请求 800 次粒子去噪计算；评分方法决策时需另外编码并打分 8 个图。没有将共同轨迹前缀摊销后的墙钟时间称为等量 FLOPs。

|策略|独立 TCN 宏一致率|速度 W1|加速度 W1|行程 W1|池内距离 m|
|---|---:|---:|---:|---:|---:|
|无重采样|71.9%|0.883|0.221|120.7|80.8|
|均匀多项式重采样|73.3%|1.010|0.202|124.6|69.8|
|采样中 GAF|73.3%|0.945|0.229|104.1|50.3|
|错误目标采样中 GAF|76.4%|0.928|0.212|121.0|39.0|
|末端按概率选择|74.7%|0.843|0.224|111.0|80.8|
|限制权重集中＋系统重采样|74.4%|0.935|0.213|118.4|69.4|

每组最终返回的 99 条全部通过图检查、无耗尽；表中多样性评估的是返回单条前的八候选，末端筛选行的池内距离继承未筛选池，不能声称单条输出本身保留该多样性。首轮采样中相对均匀控制的独立一致率差为 0pp [−6.94,+6.94]，行程误差差 −20.6m [−78.0,+8.6]。错误目标的较高一致率也提示独立指标噪声很大。

观察到多样性收缩后，做一次有明确目的的开发迭代：将权重向均匀收缩至 ESS≥6/8，改用系统重采样，同时保留均匀对照。该均匀对照逐项复现未重采样指标；修正策略将池内距离从 50.3 恢复到 69.4m。相比末端按概率选择，独立一致率差 −0.28pp [−5.56,+5.00]，行程误差差 +7.5m [−32.7,+33.1]。配对重采样 1,000 次，固定模型和候选；这轮数据复用且未做多重比较校正。早先正式测试中下游增广的结论属于末端筛选，不能用于声称采样中 GAF 已通过下游检验。

## 与上一版末端最高分规则的追加核验

复现相同 identity 候选，先验证无引导及末端按概率选出的坐标与存档逐点一致（绝对容差 0.005m），然后在相同池取最高分。最高分方案的独立 TCN 一致率 70.28%，行程 W1 为 102.23m。修正的采样中引导相对它的 TCN 一致率高 4.17pp，配对区间 [0.83,8.33]，行程 W1 则高 16.21m，区间 [−19.07,50.38]。这个语义信号依赖终端决策规则：对末端按概率选择，差值为 −0.28pp。此追加比较发生在看到初轮结果后，没有多重比较校正，不能解读为采样中引导普遍优于末端选择。
