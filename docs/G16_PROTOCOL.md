# G16 — matched data expansion and eight-class pilot
Compare two new fits under the original five labels, using only the group's strict E3 train IDs (A), or those IDs plus the published G15 training CSV (B). Separately fit eight classes (C), adding SUMO pedestrian, truck, delivery. Each fit uses class-uniform batches, 64 examples, 3,000 updates, seeds 42 and 43, AdamW 2e-4, EMA and the same path-diffusion backbone. B/C sample source 50:50 within each original class; new classes in C use SUMO only. The count of optimizer updates, label distribution and candidate budget are matched for A/B. All arms use the same physical normalization. These are new fixed-budget fits, not the historical E3 checkpoints.

Use observed 511 arc-distance increments as the target in all arms. To prevent observed trajectory duration or range from leaking through a variable-length training path, use the shape of the first 64 metres sampled on a uniform spatial grid. Exclude training tracks that never reach 64 m and report counts; all comparisons have the same rule. This tests local road geometry. Long-range route choice is external to diffusion. At inference all 512 output locations are decoded on an externally planned road. Do not impute real validation future as the requested path.

Use G15 validation only. Iterate by seed, class and sorted participant ID, take first two successfully planned starts per class per episode (report failures). Non-pedestrian paths follow permitted directed lane successors using the frozen original road prior and 4,096 m budget. For pedestrians choose an actual nearby pedestrian-permitted normal sidewalk with at least 220 m ahead in one direction, using only start and map. This pedestrian demonstration covers single-sidewalk travel, not crossing navigation. Start offset capped by the planner's 2 m tolerance. Use identical conditions and four matched noise draws per request, both model seeds. Primary metric is change B−A in class-macro travel-distance W1, secondary mean-speed W1, mean absolute acceleration W1, near-stationary fraction discrepancy, within-condition pairwise distance and route exhaustion. Compute paired 95% intervals over complete simulation episodes for the five-class estimates, conditional on two weights. Audit generated geometry on the declared graph; pedestrian segment proximity is separately reported. Report C by class on the same starts; do not infer eight-class gain from a change in aggregate. Optional secondary domain check on the original 57 development conditions, never the opened original test or G15 holdout. Do not relabel speed or acceleration summary W1 as timestep-distribution W1. GAF intentionally disabled throughout this comparison to isolate training data.

Before any evaluation scores were calculated, add secondary arm D. Identical to B but restrict the new SUMO pool to 85 different G15 training IDs per original class (425 total). Subset fixed once across both seeds using RNG seed 162000 + class index. B−D tests the incremental scale effect conditional on this one stratified subset; D−A provides the small-addition comparison. This does not estimate uncertainty across draws of training subsets.
