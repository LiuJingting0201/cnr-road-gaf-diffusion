# G21 — short-window eight-class CNN recognition
Objective: improve recognition of the actual 512-point synthesis window, separately from the six-class complete-journey literature comparison. G15 training episodes only for fitting/selection. Hold out final eight training episodes by seed for checkpoint and fusion selection; report every G15 validation ID as primary, the previously inspected 175 eligible starts as a comparable subset. No access to either frozen test. Candidate target: at least 74.9% accuracy and 70% macro-F1 on the balanced validation task; these are engineering targets, not reproduction metrics for the 2024 thesis.

Three fixed CNNs: original frozen Hilbert/GASF/GADF/MTF images with ResNet18; an alternative physical image CNN over speed and signed acceleration angular fields with fixed amplitude normalization; and a temporal convolution over motion channels. Keep the representations and conclusions separate. Two seeds per input, average seed predictions within representation for ensembles. Report per-class recall, confusion, accuracy, weighted and macro F1. Select checkpoints by monitor macro-F1 only. Select convex fusion weight in 0.1 increments by monitor macro-F1 (ties favor lower image weight); compare with standalone models. Recognition alone cannot certify generator or candidate quality. Preserve failed runs and old scores.

Before reading external validation predictions, add one spatial-resolution control using the same Hilbert source, squeeze/mirror operation and three image channels. Increase the grid from 64 to 256 cells per side by dividing epsilon by 16. Keep fixed G19 channel bounds, same training recipe and two seeds. Count encoding failures and compare on common support. Report this as a finer-grid extension, separately from the unchanged 64-cell configuration. Choose the spatial grid using only episode-monitor macro-F1.
