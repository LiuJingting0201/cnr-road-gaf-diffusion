# E5 训练条件合成数据的下游价值验证

本轮解决“合成数据是否有用”，不再把筛选教师的分类分数当作最终效果。沿用已训练的路径条件扩散及原 Hilbert–GAF 表示，使用训练 ID 条件合成，验证 ID 只用于下游评价，最终测试保持冻结。此协议在读取 E5 结果前固定。

## 合成池

固定 E3 diffusion seed42 的最终 EMA，使用 E3 的 425 条训练轨迹对应起点、类别和训练匹配路径，每条件生成 8 条 512 点运动轨迹，共 3,400 条。使用独立噪声种子 30261104，保留全部候选。这里是已知训练路径上的运动增广，不称为新路线泛化。禁止复用 E3/E4 的验证候选池进行增广训练。

验证 parent ID 属于真实训练 ID 且与验证 ID 不相交；逐一验证 source_index、标签和父轨迹对应关系，核验生成器训练文件与 checkpoint 配置哈希。原始数据、候选轨迹和权重只存服务器，不推 GitHub。

## 选择与控制组

所有合成选择共用候选池及有效掩码：5m 道路图一致、车道位置候选搜索上限 64 且无截断警告、无路径末端截断、原 GAF 可编码。沿用 E4 复核后的审计容量；不改变道路连接和距离阈值。不进行依据验证成绩调整的速度拒绝。若某条件全部候选无效，使用同一随机回退并计数，不能默默减少某一方法的训练样本。

GAF 选择器为 E2 512 点原编码 ResNet18 seed42 的固定最终 checkpoint；普通轨迹选择器为 E4 xy_motion_tcn seed42 的最终 checkpoint。它们均仅使用真实训练数据训练。分数并列采用预先固定的共享随机优先顺序。

| 组别 | 训练数据 |
|---|---|
| real_only | 原 1,437 条真实训练轨迹 |
| repeat | 真实数据 + 425 条对应父轨迹重复 |
| timewarp | 真实数据 + 425 条对应父轨迹时间扰动 |
| synthetic_random | 真实数据 + 每条件随机选一条，共 425 条 |
| synthetic_gaf | 真实数据 + 每条件原 GAF 选择一条，共 425 条 |
| synthetic_tcn | 真实数据 + 每条件普通轨迹模型选择一条，共 425 条 |

五个增广组的额外标签完全相同，参与者数量为公交57、摩托车66、汽车225、自行车56、出租车21；不合成人行轨迹。真实下游任务保留六类，避免把移除困难类别包装为增益。时间扰动为单调采样位置 u=t+a·sin(2πt)，a 均匀取自 [-0.02,0.02]，固定两端并线性插值；只是下游训练的简单扰动对照，不称道路仿真。

## 下游学习器与公平预算

固定两个架构：已有原轨迹 TCN，以及两层、隐藏维度64的双向 GRU 加均值池化分类头。前者与一个筛选器同家族，后者用于检查收益是否跨架构；不进行架构或超参数搜索，不复用筛选器权重。

每组每架构使用随机种子100/101/102，从头训练；固定 1,150 次 AdamW 更新、batch64、学习率2e-4、权重衰减1e-4、梯度裁剪1。训练有放回均匀抽样，每次严格64条，各组总曝光数都是73,600；不同数据集长度不允许通过更多训练步数获得优势。归一化与类别权重仅由原真实训练集计算，并在所有组冻结。

报告最终一步 checkpoint，不按验证最优挑选。保存中间曲线用于诊断，但不据此调参。共 6 组×2 架构×3 种子=36 次正式下游训练；2步运行检查另列，不计入效果。

## 评价与解释

在相同164条真实验证轨迹上评价六类 macro-F1、准确率、每类召回和混淆矩阵。对真实-only、重复、随机合成做配对差异；按类别分层、车辆为单位做2,000次配对重采样。置信区间条件于一个生成器和固定合成池，未覆盖生成器随机性，也不校正多重比较；这是开发探索，不能宣称最终显著性。

GAF 合成必须与随机合成及重复/扰动对照一起判断。只优于 real_only 而不优于 repeat，可能只是改变了类别频率；只在与选择器同家族模型上改善，不是跨架构价值。若没有增益，保留负结果，不继续刷辅助分类器；下一步应检查训练覆盖、运动真实性或不同合法候选路径，而非改写本轮目标。

队列入口 `scripts/run_augmentation_e5.py`；服务器运行目录 `runs/augmentation-e5`，数据目录 `data/processed/augmentation-e5`。只有完整数据构建、两种学习器运行检查、36次正式训练和汇总全部通过才写 complete.json；任何异常写 failed.json，恢复前先读状态，禁止重复启动。
