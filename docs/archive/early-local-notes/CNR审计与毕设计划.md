## 审计发现与处理优先级

### A01 高优先级 标准化与默认裁剪不匹配

证据：`week06/scripts/trajectory_diffusion_common.py:541` 使用 z-score，`:490` 重建 DDPMScheduler 而未设置 clip_sample。官方默认 clip_sample=True、clip_sample_range=1.0。因此在标准默认实现下预测干净样本被限制到正负一个标准差。absolute 和 delta 均受影响。

影响：空间覆盖缩小、步长尾部截断，可能抬高只检查上界的通过率。不能将影响大小直接等同于历史模型结果的全部原因。

处理：新 raw 训练/采样显式 clip_sample=False，采样器从保存的完整配置恢复；GASF 图像范围裁剪另行定义。先做有限值、归一化往返与支持区间检查，保存采样配置。小规模训练后比较开关裁剪、同噪声同权重的采样差异。

参考：https://huggingface.co/docs/diffusers/api/schedulers/ddpm

### A02 高优先级 反射补长改变了交通行为

证据：`week05/scripts/regularize_existing_delta_dataset_to_224_by_bounce.py:314` 实际反向遍历位置并参与训练；主实验数据中 72.45% 的 ID 被修改。

处理：新基准使用真实连续窗口；保留旧 bounce 数据作为历史比较，不能称作未修改真实轨迹。第一阶段选 64 点，不对短轨迹镜像补齐；记录被排除的 ID、类别和长度分布。

### A03 高优先级 经验 support 含测试数据且真实样本自匹配

证据：`week06/scripts/evaluate_decoded_empirical_support_alignment.py:33-48` 用全部真实轨迹建索引，真实基线也是其中子集。真实距离为零是构造结果。`sample_week05_gasf_road_guidance.py` 的经验距离场也遍历所有 labels_absolute。

处理：经验 support/guidance 仅使用训练集；真实验证/测试样本到同一训练 support 的距离作为基线。显式区分点集距离和道路合法性，路网与坐标未核实时不发布 off-road 合法率结论。

### A04 高优先级 滑窗后随机划分可能泄漏原始轨迹

证据：`week05/scripts/window_existing_delta_dataset.py:156,354` 在生成窗口后按 sample_id 随机划分；bounce 脚本可选 sliding 模式也存在此风险。相邻窗口可共享大量点。默认 truncate 一车一条时不能据此宣称旧主实验已发生窗口泄漏。

处理：先按 source_file/run/vehicle_id 分组分配 train/val/test，再切连续片段及窗口，所有派生表示复用同一 manifest。自动检查 source_id 交集为空；如有多次仿真则增加按仿真运行留出。

### A05 中高优先级 起点与位移独立抽样造成比较混杂

证据：`trajectory_diffusion_common.py:499-503,633` 将生成 delta 与独立训练起点组合。guidance 采样脚本的 sample_starts 进一步从全体数据抽起点。

处理：新核心实验统一为给定起点的生成任务，所有模型看到相同起点；禁止把目标完整 GAF 或终点默认为可用条件。旧无条件结果与新条件结果分别报告。

### A06 中高优先级 第二份数据时间断档与位置跳变

实测：主要时间间隔 0.25，有 2,158 个相邻步偏离该间隔，最大间隔 1039.25 个原始时间单位；44 个相邻步的位移率超过 100，最大约 692（单位待确认）。这不是自动剔除全部相关车辆的依据。

处理：先按类别检查 JSON 中定位的极端样本，结合 vehicle_speed、时间间隔和地图判断传送/重现/记录异常。时间断档处分段，禁止跨长缺口插值。统一时间网格时记录采样率、速度定义与滤波方法。第一阶段不混用两份数据。

### A07 中优先级 标签和逐点时间未保留在后期派生契约中

证据：`build_delta_displacement_paired_data.py` 的 PairedSample/metadata_row 保存起止时间但没有 class 和逐点时间数组。第一份单一类别使此缺口不明显，第二份会影响类别条件和动力学分析。

处理：在新的 canonical schema 中完整保留原始类别与时间。速度与加速度必须基于实际 delta_t，不能把每步距离直接叫速度。

### A08 中优先级 指标选择与比较范围不足

证据：旧 FID 脚本默认 real_split=all；接受规则对位移、bbox 等仅设上界，可能偏爱短/静止轨迹；历史 absolute-GASF 训练记录为 20k 而其他模型不一定相同；多种结果仅有报告，没有当前仓库可复算的样本和权重。

处理：验证集选择 checkpoint，测试集仅用于冻结后的最终报告。上界规则之外评价分布和覆盖，加入静止/训练轨迹抽样诊断基线。比较报告参数量、训练样本曝光量、采样步数和 GPU 时间；不能比较不同空间中的训练 loss 大小断言模型更优。

## 毕设研究问题与组内工作定位

建议题目：基于 Gramian Angular Fields 与扩散模型的交通轨迹生成及表征比较。

研究问题：

1. 组内为分类采用的 Hilbert/GAF 表示，在重建与生成任务中分别保留和损失什么？
2. 在数据和条件一致时，GASF 与直接序列、绝对位置与位移分别如何影响生成质量？
3. 是否能通过可逆构造、稳定采样和合理数据处理，使 GAF 路线成为可用的轨迹生成方法？

必须保留的组内成果：分类论文的背景与表示定义；既有 Hilbert/GAF→decoder 诊断；约束 GASF 的浮点可逆性、PNG 量化与符号歧义结果；GASF 生成主实验。负面或中性结果也如实报告，不以必须胜过 raw 为前提。

优先积极路线是 absolute-position GASF。它已有训练实现，避免 delta 积分，同时完整保留 GAF 作为生成空间。既有 20k 模型虽未完成评价，但现在算力充足，可以在新协议下公平重训。无需为复用旧 checkpoint 迁就旧数据问题。

## 新基准协议

第一层只用 vehicle_positions_TS_New，单类乘用车、64 个连续观测点、步长 1。若单位证实为秒，则覆盖 63 秒；不能先称其为 64 秒。保存全部真实时间，避免插值。按车辆先分组，再切窗，训练可 stride=32，验证/测试采用非重叠窗口并限制每车贡献，防止长轨迹主导。

核心任务为 p(轨迹 | 起点)，同一批留出起点为所有方法提供合法条件，每个起点生成多条轨迹。条件起点来自测试任务输入不是泄漏，但不可再称为完全无条件生成。真实参考与条件起点的采样策略必须固定，测试时不给终点、完整目标图像或未来 bbox。

所有方法使用同一个 split manifest、相同连续点和坐标系。标准化只 fit train，变换参数持久化。GASF 使用浮点数组和明确的可逆归一化，PNG 仅展示。新条件实现统一提供起点；GASF 的原生成起点热图改为已知条件输入，absolute 的首点与 delta 积分起点采用一致确定性约定，首点不计可学习误差。

模型工程完成后先验证少样本过拟合和编码往返，不能只靠 loss 下降判定正确。

## 最小核心实验矩阵

| 编号 | 生成对象 | 目的 | 定位 |
|---|---|---|---|
| E0 | 真实路径编码再解码，无生成器 | 单独量化 GAF 表示、归一化、存储误差 | 必做诊断 |
| E1 | GASF absolute x/y | 保留组内路线，避免积分漂移 | 主要候选方法 |
| E2 | GASF delta x/y | 与已有工作连接，检查累积误差 | 主要对照 |
| E3 | Raw absolute x/y | 同起点条件下直接位置生成 | 基线 |
| E4 | Raw delta x/y | 将位移影响与图像表示影响分开 | 基线 |

先每组一个种子，共四个探索训练，冻结超参后各三个种子，共十二个最终训练。探索运行只有满足最终协议才能计入最终种子。优先各用一种网络：2D U-Net 对 GASF，1D U-Net 对 raw；不再扩展到六种 backbone。记录参数量/时间差，2×2 比较仍是端到端系统比较，不能声称完全隔离网络架构因素。

最小必要消融：raw clipping 开/关的同权重采样；GASF absolute 的纯 MSE 与 MSE+diagonal（先单种子，进入主结论才补种子）；浮点与量化 round-trip。旧 bounce 与新真实窗口不能直接作为纯模型提升对比，若要归因必须固定其余设置另做小消融。

## 评价与完成门槛

- 数据门槛：原始 ID 不跨 split；无跨断档窗口；每点时间/类别可追溯；归一化来源仅 train；不把反射点当真实观测。
- 数值门槛：float64 absolute→delta→absolute 往返最大误差建议 <1e-6 坐标单位；float32 GASF 往返建议 <1e-3，超出则先报告量化/饱和原因。这是工程验收阈值，不是科学质量结论。
- 有效性：有限值、跳点、速度/加速度/转角；按实际时间单位。地图确认后再加连接性和道路距离。
- 分布：长度、位移、停留比例、速度、转角、起终点与占据栅格；报告 Wasserstein/分位数、覆盖，不只均值和接受率。
- 多样性：同起点多样性、轨迹聚集、训练样本近邻；训练集原样抽样和静止轨迹仅作为诊断，不能伪装成条件生成 baseline。
- 经验 support：train-only；比较留出真实轨迹到 train support 的非零基线。
- 图像指标：FID 仅辅助，固定表示/预处理/样本数，不能比较不同通道语义的 FID 得出轨迹优劣。GAF 分类器只有在独立留出数据上验证预处理和可靠性后才用于辅助语义评价。
- 统计：预设三个训练种子，报告均值和离散程度；按源车辆/条件起点做分组 bootstrap，不把重叠窗口当独立样本。
- 最终评价按方法每种子先规划至少 1,000 条生成样本，使用固定起点集合及相同采样次数；在验证阶段确定预算，测试协议冻结后不根据赢家修改。

门槛不是“GAF 必须赢”。若 GAF 仍落后，交付可信的比较、定位误差和有效的可逆设计；若改善明显，则围绕 absolute-GASF 改进展开。不得使用 cherry-pick 图或不断修改阈值制造成功。

## 六类数据扩展与停止规则

第二份数据用于加强与组内交通方式分类工作的连接，默认属于核心完成后的扩展，不与第一份混训。

先保留 class2，按时间缺口切段，检查位置跳变和缺失 speed，再考虑统一到与第一层相同物理采样间隔。0.25 与 1 的输入不能仅按点数强行等同；清洗后重新统计每类保留车辆数。按类分层、按车辆分组划分，稀有类别设置独立报告，避免总体准确率掩盖 taxi/bus 等表现。

只选择最佳 GASF 和最佳 raw 各一个，加入相同 class 条件与起点条件。分类器训练与生成器评估共享明确的留出边界，不能用被测试车辆训练分类器后再称独立评价。无可靠分类器时仍可用分类型运动统计和空间分布完成扩展。

不把完整真实 GAF 作为生成条件再声称生成新轨迹。GAF 特征条件方案需明确特征来源、推理可得性、信息瓶颈、复制检测，并与简单类别条件比较；默认放 future work。
