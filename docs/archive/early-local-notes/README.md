# 轨迹合成毕设：本轮交付

核心实验、锁定测试和图表已完成，自动迭代已暂停。详细结果见 [论文结果总结](THESIS_RESULTS_SUMMARY.md)。完整代码与记录位于 [私有GitHub仓库](https://github.com/LiuJingting0201/cnr-road-gaf-diffusion)。

## 合成数据

- [训练侧合成轨迹](training_synthetic_trajectories.zip)：E5实际使用的随机/GAF/TCN三个版本，各425条，每条512点。只含生成部分，不含真实数据。三个版本是替代对照，不能合并视为互相独立。
- [最终测试条件下的合成轨迹](final_test_synthetic_trajectories.zip)：1,272条全部候选及四个各159条的筛选版本；筛选版本来自全部候选，有重叠。供结果复核与展示，不能加入训练后继续称这份测试独立未见。

ZIP内有README、catalog.json和压缩CSV。CSV字段为time,id,x,y,type；时间是每条轨迹从0开始的相对秒数，间隔0.25秒，共127.75秒。坐标是MoST局部SUMO米制XY，不是GPS。type保留原规范拼写，包括bycicle。每条独立生成，不构成联合交通流，不保证车辆间无碰撞或信号灯遵守。只覆盖严格道路移动子集的五类，不包含行人。

## 结论边界

路网条件扩散直接合成已跑通；最终严格测试53个条件中，共享路径解码带来100%的当前道路图一致率。覆盖仅占全部270个测试ID的19.6%，其中出租车仅2个条件。扩散相对经验运动在行程分布上存在有条件改善，速度和加速度区间跨零，不能声称全面优越。

GAF同家族评分提高没有转化为稳定的真实数据增广收益：TCN仅真实数据macro-F1为76.92%，GAF合成为71.69%；GRU为64.38%与62.68%。负结果、全部对照和限制都已保留。当前测试已暴露；后续若改模型，应准备新的独立评价。
