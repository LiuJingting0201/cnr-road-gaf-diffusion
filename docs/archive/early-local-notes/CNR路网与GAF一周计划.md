# 路网约束与 GAF 类别语义的轨迹扩散合成一周计划

本计划取代此前四周、以单类比较为主的安排。用户目标是硕士毕设，一周得到可汇报的模型结果；已有独占四张 L20，必要时可用八张 H20。训练是核心工作，不以省训练为目标。服务器已连通并建立独立项目；当前实施状态以 README 和实验 complete.json 为准，下文为完整一周目标，不代表所有模块已完成。

## 研究主线

在给定路网、起点与交通参与者类别时，扩散模型合成新轨迹，使其同时满足空间通行约束、合理的运动统计与可辨识的交通类别语义。组内 GAF 分类工作提供语义表征和验证基础，历史 GASF 生成作为完整对照。题目仍属于轨迹合成扩散模型，不改成地图重建或单纯表示审计。

工作假设：显式路网条件改善空间有效性，类别条件控制交通方式，GAF 分类反馈有望改善生成轨迹的语义一致性。这些是待检验假设，不预设最终模型一定优于全部基线，也不宣称未经文献查证的首创。

## 第一天的数据与地图验收

保留逐点时间、原始 class2、ID 和数据 hash。按车辆、类别分层划分 train/val/test，再分段和取窗；不得先滑窗后随机分割。第二份存在 2,158 个非0.25间隔、最大1039.25间隔，断档处切段。逐项查看跳变样本，不因为离群就自动删整个类别。保留缺失 speed 标记，位置导数与记录 speed 分开检查。

先从连续0.25间隔片段提取64点窗口，物理跨度15.75个时间单位（若原始 FCD 时间未变换则为秒）；再用128点31.75秒窗口做时域长度对照。不能把上一版第一份数据的64点约63秒与此混为一谈。若采用降采样，所有方法和分类器保持相同协议，并重新检验类别可辨性。

地图按行人/自行车/机动车分别读取车道允许通行属性；保留路口内部连接、方向与道路拓扑。核验真实留出轨迹的车道距离、方向及合法连接，先测量地图基线误差再设置生成评价阈值。几何配准参数如需微调只用训练轨迹，测试不参与调图。地图公开几何本身可作为全部样本共同环境条件；轨迹密度、类别先验只能从训练集估计。

## 模型与组内 GAF 的具体关系

主生成器采用坐标序列扩散，条件包括交通类别、起点、固定地图或局部地图特征。初始地图可用可通行区域、距离场和方向通道，通过轻量地图编码器注入1D U-Net。局部裁剪范围由起点和固定半径定义，不能用真实终点或未来 bbox 定位。

GAF 分支使用组内 GASF/GADF/MTF + CNN 思路训练交通类别分类器。若无法获得原论文完整预处理与代码，明确标注为组内方法思路的重新实现，不能宣称复现原指标。优先核对原论文，再固定可重复的预处理；不把64点图任意缩放到224后直接套未知 checkpoint。

第一版 GAF 用于冻结后的类别一致性评价与候选选择。对每个起点/类别生成固定数量候选，结合地图有效性与 GAF 分类分数排序，报告所有候选及选中子集的质量、多样性、保留率和成本。分类反馈是否有额外作用由同预算随机选择、只地图筛选、只类别筛选及联合筛选消融决定。

第二版尝试采样期语义 guidance，仅在编码和分类器对坐标可微时使用。原始 Hilbert 索引、量化 MTF、PNG 操作不可默认为可微；可另训浮点 GAF 分支，但必须与组内原编码分类器分开标注和评价。语义 guidance 不是第一版系统出结果的阻塞项。前述 GAF 结构辅助 loss 可以作为备选消融，不再凌驾于明确的路网/类别目标。

避免同一分类器既被优化又担任唯一裁判：保留独立初始化/架构的审计分类器，加每类运动统计、地图指标和多样性评价。分类器仅以训练数据学习、验证集选型，最终留出真实车辆先测 macro-F1/各类召回/混淆矩阵。Taxi 与私家车等类别可能本身难以由短轨迹区分，应报告该上限。

## 实验矩阵与 workload

| 组别 | 模型或系统 | 回答的问题 |
|---|---|---|
| G0 | 组内 GASF 图像扩散、解析/已有解码路线 | 历史路线在统一数据上表现如何 |
| B0 | 类别+起点条件的直接轨迹扩散 | 无显式地图的基线 |
| B1 | B0 + 地图编码条件 | 地图条件本身的贡献 |
| B2 | B1 + 距离/方向 guidance | 采样期地图约束的贡献 |
| P | B2 + GAF 类别反馈或候选选择 | GAF 是否提高语义一致性且保留多样性 |
| P-topo | 对 P 作连接感知的轨迹匹配/投影 | 最终交付能否沿合法连接行进 |

G0、B0、B1 是训练组，B2/P/P-topo 优先复用 checkpoint 作推理实验。G0 的 absolute-GASF 为主，delta-GASF 是已有路线消融。训练 GAF 分类器与独立审计分类器。核心模型补三个随机种子；在第四天冻结后才进行最终重复。规划约12–18个主训练任务（含分类器与核心表示消融），另有固定预算的采样矩阵；根据首日实测单任务 GPU 小时确定并发，不能用历史日志推断当前硬件耗时。

补充消融：无类别条件、无GAF反馈、无地图约束、64/128时域、absolute/delta GASF、raw裁剪开关。文献参照优先 DiffTraj（https://arxiv.org/abs/2304.11582）；路网条件方案与 ControlTraj（https://arxiv.org/abs/2404.15380）对照定位。不把改写的简单基线称为完整复现；完整外部复现如占用过多时间，则保留明确实现说明。

## 路网约束的验收含义

距离场只能使点靠近道路，不保证转弯与车道连接。最终拓扑处理必须沿有向可通行车道序列连接，验证连续段而非仅逐点吸附，保持时间对应，约束过大的修正量；无法修复的样本明确拒绝。

所有方法分别报告原始输出、统一拓扑后处理后输出和拒绝率，避免把后处理作用归功于网络。原始生成主要衡量学习质量，最终系统衡量可用性。地图约束通过不等于多智能体无碰撞，也不等于完整遵守动态信号灯；本周目标为单条轨迹的几何、方向、连接及运动合理性。

## 最终故事与成功标准

组内已有工作用 GAF 识别“是什么交通方式”；本项目研究如何扩散合成“在路网上运动、且具有该方式特征”的新轨迹。贡献分为路网感知生成、GAF语义连接与严格的联合评价，历史图像生成实验提供对照和动机。

一周成功标准是得到可复现的训练模型、地图和语义双轴比较、关键消融与失败解释，不保证新模块所有指标都胜出。论文中区分已证实结果与方法假设，不将更多训练次数本身当作贡献。
