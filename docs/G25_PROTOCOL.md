# G25 — representation audit after G24
Distinguish (1) paired information shared by frozen spatial and speed readers on observed SUMO trips, (2) class information decodable from the spatial penultimate layer, and (3) whether speed guidance shifts a matched generated trip in a class- or mode-specific direction. This is an exploratory metric audit prompted by G24, not a replacement for its prespecified endpoint. Do not feed velocity to the spatial classifier or train the speed reader to predict class. No claims about every diffusion hidden layer or real-world causal effects.

Use the frozen 512-D global-average-pooling layer before the linear classification head in both ResNet18 readers. On the 6,033 G22 train trips fit representation transforms, spatial class probes and class/mode prototypes. Choose probe regularization on 1,126 monitor trips only. Score G23's 3,021 external reference trips and G24's separate 192 reference trips, then the matched G24 unguided, guided and permuted-target candidates. These development cohorts were viewed in earlier experiments; no test access. Check that recomputing the original head on the features reproduces the recorded class outputs.

Shared structure: linear CKA on each branch's first 32 train-fitted PCs, with a within-class/episode permutation null. Repeat after removing participant means, and after linearly residualizing class plus log length, log clock, average speed and endpoint coordinates (fit nuisance models only on training). Report all eight and the six motorized classes, as well as CKA of class centroids vs label permutations. These are alignment diagnostics, not percentages of shared information.

Spatial readouts: frozen head accuracy and macro F1, spatial-only regularized linear probe, and cosine class-prototype margin. Define a within-class speed-mode direction from training spatial embeddings (positive mode centroid minus complement, normalized), requiring at least 20 training IDs on each side. Validate these directions on actual G23/G24 modes by within-class AUC with at least five examples per outcome. On G24 generated pairs compare guided vs plain and vs permuted using target-class probe probability, cosine class margin and within-class target-mode direction; report coverage and paired whole-episode intervals conditional on the fixed seeds. A change in an alternative readout alone does not establish better physical motion. Do not rerun G24 sampling or search gradients/steps for a favorable metric.

Include an additional distributional criterion: class-macro empirical squared MMD (RBF kernel) between generated and same-request SUMO reference embeddings, separately for spatial and speed images. The 32-D PCA map and class-specific median-distance kernel bandwidths are fitted only on G22 training rows. Weight every request equally, average over both generator seeds, and bootstrap complete G24 episodes. Use the nonnegative empirical kernel-mean distance; it is a finite-sample diagnostic, not an unbiased population estimate. This measures closeness to a class distribution rather than maximization of the target logit.

Secondary denoiser-space diagnostic: to distinguish CNN embeddings from diffusion state, take G24 bus/car starts whose full prescribed path passes both directed class checks. Replay the unguided DDIM path with identical noise, start and road. At ten evenly spaced intermediate denoising evaluations compare the target-class versus alternate-class clean-prediction direction (proportional to alternate epsilon minus requested epsilon) to the speed-mode gradient at the very same state. Use the G24 smooth schedule to weight times; report the full token direction and the progress-only direction, plus a target-permutation contrast. This is a local alignment of two interventions in the model's normalized coordinates, not a measure of final trajectory fidelity or a new sampling policy; duration is encoded relative to a class-dependent training-speed baseline.
