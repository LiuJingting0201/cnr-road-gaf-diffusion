# 下一轮：生成轨迹是否帮助真实GAF分类

本文件为实验设计，尚未执行。目的：在独立真实车辆上检验生成增广，而不是只用分类教师给生成器打分。

## 数据与信息预算

所有分类训练使用同一most64训练车辆；验证仍为原冻结的真实车辆划分。生成器、路径转移先验、GAF教师均只见训练车辆。合成起点必须来自训练集，路线从这些起点重新规划；不能拿已有验证起点的合成结果做增广，也不能用训练匹配的真实未来路线冒充自由规划生成。

现有生成器只覆盖五类移动窗口。因此合成只补这五类，行人仍使用真实训练样本；同时报告六类整体、五类子集及各类F1。不能宣称已经完成六类生成。

不做伪低数据量实验：现有生成器和教师使用完整训练数据，不能拿它们生成的数据与仅用10%标签的分类基线比较后宣称低数据收益。若做低标签实验，生成器、教师和统计也必须按对应信息预算重训。

## 对照与预算

固定生成器及弱引导0.3，预先固定每类合成数量；无引导/GAF/TCN使用相同训练起点、规划路线、初始噪声。不能按审计得分筛选合成样本。加入等量真实重复采样与简单运动扰动对照，排除类平衡或额外训练次数导致的收益；若教师知识迁移可能解释结果，补真实轨迹上的教师蒸馏对照。

分类器同结构、同初始化种子、同总更新步数、同真实/辅助样本比例、相同归一化（仅真实训练数据估计）和损失类别权重。所有组都保留。主报告固定末步；最优验证步仅辅助，不将多次挑选的最高F1作为唯一结论。

## 评价与解释

真实留出车辆macro-F1、每类F1/召回、混淆矩阵，三种子并按车辆聚类估计差值区间。先验证合成池与验证/测试车辆无交集，查训练近邻和重复率。不能把生成引导教师自身分数当作增广效果。

如果合成增广未优于重复采样/简单扰动，据实保留负结果；GAF引导机制有效与下游增广有效是两个独立结论。没有收益时优先查合成分布覆盖与教师偏差，不增加无关课题。
