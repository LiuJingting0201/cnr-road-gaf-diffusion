# G34：固定采样时长，分离GAF对运动的反馈

2026-11-06，在新候选生成与评分前固定。G33已经全部完成；本轮是依据G33提出的有限开发机制对照，不是新的盲测，不更改G33结果。

## 问题与依据

G33原生模型相对257表示改善原生加速度分布，但同池速度GAF最高分选择将目标概率提高到约0.99，同时时长W1从Uniform的57.78/51.59秒增至74.42/77.68秒，原生速度W1也增加。分类置信度偏好可能通过选择快慢行程改变本已采样好的时长分布；这只是待检验机制，不据此断言所有负效应由时长引起。

本轮问：**时长由生成器先抽好并保持不变时，GAF是否能在同一路线、同一车型和同一总时长下改善运动模式？** 不改变CNN、表示尺度、评分权重、数据或扩散权重，不扫描超参。

## 固定执行

沿用G33全部100个事前请求及97个可解码地图条件、原生模型seed42/43、两个固定教师。每个request/modelseed从原G33 Uniform规则（seed33073的request-ID排列首slot）确定一个候选ID，使用该候选ID和模型seed重演训练侧时长先验的抽样，得到唯一T。既不读参考时长，也不读GAF分数来选择T。

固定K8、DDIM100。八个候选共享该T，各自初始运动噪声仍按原候选ID派生，时间变长表示、去噪器、条件、精确地图解码均不变。Uniform对应slot的新轨迹应与G33该slot相同，这是一项实现一致性检查，不能通过更换slot规避失败。

新代码独立放在g34_fixed_duration.py；G33训练、生成、评分和评价源码不变。隔离输出在g33-job/g34-data，拒绝覆盖。记录新代码与全部继承来源hash、真实网络调用和耗时。对于兼容G33评分器的输出，保留prospective_generation数据权限标记，同时明确experiment_phase为G34固定时长开发诊断；不能隐去新规则后混入G33主表。

完成生成后使用未改的Uniform/S/V/SV四策略，仍然共享同一K8池。使用既有独立SUMO开发参考做事后物理评价，100请求分母和94可配对支持不变。参考已被G33分析过，所以本轮只能作为开发机制证据；若以后主张普遍有效，需要预定的新仿真实现复核。

## 验收和解释

两个种子各自比较四策略的十项物理W1、原生速度/加速度W1和固定覆盖。所有策略的时长应相同；平均速度也主要由既定路长和T决定，不把这些恒定量当反馈收益。主要可变化的量是速度分布形状、加减速、停止比例、停走频率、最长停车/巡航及四秒变速。

同时报告全池多样性、目标类概率与实际改选率；教师自身高分不算质量。与G33的差别只回答限制反馈自由度的作用，不能声称新架构胜利或GAF角场优于其他同信息评分器。本轮仍是末端选择，不是采样中梯度guidance。
