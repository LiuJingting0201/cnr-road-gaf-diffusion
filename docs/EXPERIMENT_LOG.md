## 2026-11-04：启动与表示研究设计

已完成：独立 Git 仓库和四张 L20 开发环境；车辆级分组数据；七项基础测试；两条 100 步链路试跑。当前基线代码不是完整毕设模型。

### R1：Hilbert / GAF 表示对照（预注册）

问题：原组内 Hilbert-GASF/GADF/MTF 表示在当前时间窗口上是否保留交通类别信息；细化 Hilbert 网格、使用位移 GAF，以及直接序列编码器分别有何影响。

统一数据：most64，26,642 个训练窗、2,791 个验证窗；车辆 ID 不重叠。0.25 原始时间间隔、64 点；不做 squeeze 或镜像补齐。坐标边界和位移统计只由训练窗拟合。测试集不读取。

统一优化：AdamW，学习率 2e-4，weight decay 1e-4；batch 128；4,000 更新；每 500 步及第 1 步验证；按验证 macro-F1 选 checkpoint。类别损失权重为训练频次平方根的倒数。随机种子 42、43、44；独立 minibatch 随机数生成器确保同种子各模型批次顺序一致。

| 变体 | 输入与编码 | 目的 |
|---|---|---|
| hilbert_coarse_rgb | eps=.0037；GASF/GADF/MTF；固定理论范围转 uint8；CNN | 原有编码默认精度的迁移基线 |
| hilbert_fine_rgb | eps=1e-7；其余同上 | 隔离空间精度影响 |
| hilbert_fine_tcn | 相同细 Hilbert 序列及逐窗归一化；TCN | 判断二维成像是否必要 |
| delta_gaf | 训练集尺度 sigmoid(dx,dy)；GASF/GADF 四通道；CNN | 保留运动尺度的可微表示候选 |
| xy_motion_tcn | 标准化 XY 与 dx,dy；TCN | 直接序列强对照，使用相同原始信息 |
| xy_gaf | 逐窗 XY GASF/GADF 四通道；CNN | 初始试跑表示对照 |

这些是统一新协议下的表示实验，不是原论文的精确复现：原来的长轨迹长度处理、数据文件、分类架构和像素缩放存在版本差异。CNN/TCN 的参数量与耗时分别记录，不声称计算量严格相等。Hilbert 分类分数不能直接证明生成收益。

编码验收：逐点与原仓库 Hilbert 递归实现比较；浮点 GASF/GADF/MTF 与 pyts==0.13.0 比较；常数序列与分箱边界单独覆盖。测试通过后才启动训练。

执行记录：服务器基础及表示测试首次运行 10/10 通过（7.28 秒）。完整 most64 文件已经通过原始预处理文件 SHA256 校验；baseline-001 已触发。测试集仅做传输完整性校验，不读取其预测指标。

研究边界：本轮验证结果用于选择后续生成实验候选。正式结论仍需要空间留出、生成质量与多样性、独立审计分类器、增广对照。GAF 没有稳定收益时不预设保留。

### 下一轮生成实验

完整数据坐标扩散作为 B0；加入可通行道路条件作为 B1。GAF 首先用于同一批候选的固定预算排序，与随机选择、仅地图、直接序列分类器评分对照。只有表示验收和分类能力成立后，才尝试可微 GAF 的训练或采样约束。原始 Hilbert/MTF 不直接用于坐标梯度引导。

代码、预注册和结果摘要推送至 server Git 远端；每个训练 config 保存提交 hash、数据文件 hash、随机种子和硬件。完整权重和数组保留在服务器 runs/，不进入 Git。

### G1：固定候选池语义选择（预注册）

使用已经完成的 baseline-001 坐标扩散 checkpoint；这不是地图条件生成器。验证集每类最多选择 8 个不同车辆，每车随机选择一个窗口，只把起点和类别提供给生成器。每个条件生成 4 组独立的 8 个候选，所有策略共用完全相同的候选池。采样种子 2026，DDIM 50 步，无 x0 裁剪。

对照：随机（固定候选下标 0）、仅地图、细 Hilbert RGB 评分、位移 GAF 评分、直接序列评分，以及各语义评分与地图筛选的组合。组合统一先按可通行车道平均距离取前 1/4，再按目标类别概率选择；不事后调整权重。所有语义选择器均使用 R1 seed42 checkpoint。

审计器：独立训练的 XY/motion TCN seed43、44 概率集成。它与直接序列选择器架构相同，必须披露这一偏好；同时报告不依赖分类器的路网距离、每类速度 Wasserstein 距离及条件内输出离散程度。道路指标排除已给定的起点。离散程度大不意味着多样性合理。

本轮是候选筛选效用诊断，不把筛选收益归为生成模型学习收益。基础生成器存在速度和道路偏差，分类器可能遇到分布外样本；若语义分数与物理质量冲突，应记录冲突而非仅报告分数改善。独立测试、拓扑合法性和下游增广仍未覆盖。
