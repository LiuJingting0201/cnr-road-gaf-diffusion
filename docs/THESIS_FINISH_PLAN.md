# 毕设收敛计划：完整道路条件扩散轨迹合成与 GAF 反馈

2026-11-06 更新。执行细节以 [G33 协议](G33_PROTOCOL.md)为准；本页收拢论文主张与下一步交付，不把计划写成结果。

## 导师视角：只保留两个核心问题

**给定道路计划路线、参与者类别及明确端点，扩散能否合成完整、带物理时间的轨迹；空间 GAF 与速度 GAF 的类别反馈，能否进一步改善交付轨迹的运动质量？** 输出是 `time,id,x,y,type` 合成数据及可复现模型。SUMO 提供监督与独立参考，地图解码提供道路约束，均服务于这两个问题，不另立分类、地图或仿真研究主线。

空间分支继承原 Hilbert→GASF/GADF/MTF，不额外接速度；速度分支由同一轨迹的位置和时间计算速度序列后编码。两支均为本项目自训参与者类别网络，没有组内现成 CNN。信息同源不保证互补；分类准确率、教师高分与生成收益是三个不同命题。

## 当前事实与执行边界

- G33 已直接准备 SUMO 原生完整车辆行程 **925 train / 126 val**，保留 0.25 秒采样及停止段，并实际执行两时钟×两种子的四次扩散训练和两个固定教师训练。拟合、采样、质量评价分别核验完成标记；目前不据训练完成宣称生成改善。
- 独立新仿真已执行：事前固定 **100 请求，100 到达，97 参考通过既定检查**。三个失败及被接受样本中的紧急停车记录均保留；总体覆盖分母仍为 100，质量表另报每指标共同支持数，不能只展示成功子集。
- **取消 G32 手工地图构造成功作为训练前置门槛。** 训练观测中的路线—运动配对可用于监督；正式生成仅用仿真前冻结的公开计划与地图，不借参考未来路径或时长修复条件。地图解码失败留在生成覆盖中，不阻塞已可执行的训练。
- 两时钟臂和经验基线共用训练侧时长先验。完整行程时长是因子化生成器的一部分，不能称由扩散直接生成，也不能将共同先验的时长成绩归功于新运动表示。单训练场、新仿真种子及公共线路模板的复用限制必须披露。

沿用 G33 已冻结的 K=8、DDIM100 和种子42/43，不扩展实验矩阵。主表分两个面板，完整逐类指标另附：

| B：反馈 | 原生0.25秒扩散的两个种子各自同一候选池，比较 Uniform / 空间 S / 速度 V / 等权 SV 交付样本 | 相对 Uniform 的独立物理指标变化、覆盖和模式收缩；空间编码同图比例、实际改选比例及额外教师成本 |

不同单位不合成任意总分；报告既定十项统计和原生速度/加速度分布，不能只挑行程或教师分数。类内按请求等权，池内候选再等权；缺类时不报完整五类宏平均。两个模型种子分列，单场请求不冒充独立仿真重复。正文示例用预定规则选择，与总体表并列，不能替代统计证据。

| 观察到的结果 | 才允许支持的主张 |
|---|---|
| 扩散相对经验基线在独立运动质量上改善，覆盖和多样性代价同时可见 | 学得的运动模型有实际价值；道路合法性仍归于解码结构 |
| 物理时钟在生成质量上优于匹配的257点对照 | 新时间表示改善合成；G32 的重构改善本身不够 |

| SV 稳定优于较好的单分支，且覆盖/多样性无明显额外损失 | 才讨论双视图互补；空间候选几乎同图时，只能说明当前自由度不足以检验其增量 |

当前锁定的是**末端反馈筛选**，不是采样中 guidance。没有相应执行结果，不写采样引导优于筛选、跨路线泛化或合成增广收益。暂不追加多路线任务、新潜空间方法、更多 CNN 扫描或仿真扩容；先完成这张主表，再依据证据决定是否需要原计划内的有限复核。
