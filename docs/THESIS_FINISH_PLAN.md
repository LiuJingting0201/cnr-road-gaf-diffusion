# 毕设收敛计划：可信路网条件下的完整轨迹扩散与双视图 GAF 反馈

2026-11-06。此计划将任务书的下一步收敛到生成交付；G32 的执行边界见独立协议。不是已完成成果清单，也不预设 GAF 有效。

## 论文要回答的一句话

**如何在可信的交通需求和道路拓扑约束下，用扩散模型合成完整、带物理时间的出行轨迹；空间轨迹 GAF 与速度 GAF 保留的不同类别信息，分别能在什么条件下改善这些合成轨迹？**

交付物是可调用的轨迹生成器：输入地图、类别及明确的路线/起终点条件，输出 time,id,x,y,type，并附配置、模型、采样脚本和质量报告。GAF 是受检验的反馈模块；分类准确率和高分图片不代替生成质量。

空间图使用原仓库 Hilbert→GASF/GADF/MTF 编码，不接入额外速度特征；速度图只由位置与时间求得的速度序列构成。按 G28 用户更新，两支都可识别参与者类别，但分类器均为本项目自训，不是组内提供。二者同源不等于保留相同信息，更不保证对同一个采样自由度都有增量。

## 现在已有的证据与缺口

| 问题 | 已有证据 | 还不能声称 |
|---|---|---|
| 为什么空间 GAF 一度很低？ | 同配置 CNR/随机需求/原生 MoST 宏 F1 59.88/30.15/58.69%；纯几何读出也随需求恢复 | 编码无损、CNN 已很强，或单独公交站点就是全部原因 |
| 完整行程数据是否可信？ | G31 原生输出无扰动，1644 个事件段；公共计划与实际实现分列 | 1644 个独立场景，或未来路径可以当模型输入 |
| 旧生成表示够好吗？ | 257 点相对时钟对长公交平滑明显，公交速度重构 MAE 0.424 m/s | 所有既往负结果均由这一问题造成 |
| 双 GAF 对生成有用吗？ | 旧实验有分类/局部选择信号，但未建立稳定独立物理增益 | 双视图必定互补、提高分类分数就改善合成数据 |

G30 是“修正需求域后空间信息回来”的正面依据；它不是下一版完整 leg 教师的准确率。公交验证仍是训练见过的线路、同地图同公共模板，不能写跨城市或未见线路泛化。

## 三项拟形成的贡献

1. **完整行程生成系统**：从合法计划路线到物理时间运动扩散、连续坐标解码及可用数据导出。比较旧固定相对时钟与新物理时钟，对长短行程统一评价，不靠删除长行程规避困难。
2. **与生成自由度对应的双视图反馈**：空间 GAF 检查地理/路线与类别的一致性，速度 GAF 检查路线内的类别运动；在固定路线与多合法路线两种任务中区分效果，并和末端筛选、打乱反馈及非 GAF 评分公平比较。此分工是待检验假设，不写成必然成立的机制。
3. **有外部参照的质量评价**：原 CNR 作为来源仿真观测参照，原生 SUMO 需求提供可重复完整事件，生成评价覆盖路线、运动、分布、多样性与数据用途；明确随机种子独立与路线模板独立的差别。两者均不是实测道路交通。

单独“扩散+GAF”不是创新论证。[Wang 与 Oates 的时序成像](https://ijcai.org/proceedings/2015/553)已经提出角场表示；[分类器扩散引导](https://arxiv.org/abs/2105.05233)是已有方法。硕士工作需要证明本任务中的表示、条件接口和反馈设计解决了具体问题，并说明适用边界；不声称发明 GAF 或一般 classifier guidance。

## 有限实验矩阵与顺序

### 1. 接通生成接口，不再无限分类诊断

G32 只比较 257 相对时钟、1 秒物理时钟、0.25 秒分辨率控制，并实现有端点/站点约束的五类车辆路线适配。其后写 G33，先固定少量完整需求请求做训练—采样—CSV 导出闭环，再扩大到预定训练规模。行人保留数据分析，若步行拓扑未实现则明确不进入五类车辆主生成表。

G32 三臂真实检查已完成后的决策：采用 **0.25 秒变长物理时钟作为下一模型的目标**，1 秒作为运动摘要尺度。1 秒臂的逐秒误差明显下降，但原生速度/加速度残差仍高；不能只用对齐控制时钟的指标选型。原生臂平均约 1714 控制点，最长 9419，需长度分桶与显式 mask；这是表示成本，训练吞吐尚未测得。共同空间路径仍存在离散尾误差，正式地图解码保留折线顶点，另验证计划路径上的目标投影，不用 oracle 结果冒领地图接口通过。完整数值见 [G32 报告](results/g32-physical-clock/REPORT.md)。

新请求在仿真前冻结路线边实例、起止 lane/pos、站点与类别。不同 leg、不同仿真中同一 parent 均不跨数据分区；旧测试模板排除。新留出封存至配置锁定，不能复用已暴露的原测试选型。随机仿真重复不冒充新 OD。

### 2. 先训练两个扩散版本，确认模型本身有贡献

同一原生完整行程训练集、同一合法路线与类别条件：旧 257 进度扩散、新物理时钟扩散，各两个固定种子；再加不训练生成器的同路线经验运动迁移。四次扩散拟合是第一轮上限。物理时钟模型需要显式时长/长度机制、padding mask 和对 padding 不敏感的归一化，不能只给旧网络补零。

若新模型条件于总时长，采样时必须从训练侧学习的条件分布生成时长；真实未来时长仅用于明确标注的 oracle 对照。以旧模型和经验迁移为主对照，不用只画漂亮轨迹证明成功。训练步数、网络规模、总算力和采样成本分别披露；等步数不冒称等计算量。

### 3. 冻结同域 GAF 教师，再做反馈实验

只在新完整 leg 的训练/开发分区，用既定编码与固定训练规则各训练一个空间/速度教师；parent 分组验证、报告每类召回与校准，不为追准确率无限换结构。G30 的六类段级成绩不能直接移用到此任务；G33 将生成器和两个教师统一到相同的五类车辆标签。置信不足的类别不宣称强 guidance；全部预先纳入生成的类别仍保留生成评价。

新生成器固定后比较同池 Uniform、空间 S、速度 V、双支 SV 末端选择，以及一个预先固定的 SV 采样中反馈方案和标签/配对打乱控制。不扫“神奇第 76 步”。原空间 Hilbert 量化不可直接普通反传，因此空间反馈采用候选/粒子评分，速度图可检验可微更新；具体机制、归一化、噪声区间与权重在执行前写 G33，不据质量结果重选。

至少补一个同输入非 GAF 原始序列评分器的同预算比较，才能讨论“GAF 表示”而不只是“一般分类反馈”。冻结空间评分器参与选择后，其分数不再充当独立真实性证据。

### 4. 两种任务分表，避免把空间 GAF 锁死再判它无用

| 任务 | 预先给定 | 候选允许变化 | 主问题 |
|---|---|---|---|
| A 固定计划路线 | 地图、完整合法计划路线、类别、起止/站点 | 时长和沿路运动 | 速度/双支反馈是否改善停走、巡航和运动分布？ |
| B 合法路线候选 | 地图、类别、相同 OD 和共同服务约束 | 同 OD 下事前合法路线选项及运动 | 空间反馈是否改善路线—类别一致性，同时保留覆盖与多样性？ |

B 的路线候选来自训练侧公开需求/地图规划，不从验证未来轨迹抽取。主 B 固定相同 OD，避免把终点区域变化误称路线改善；仅给起点的联合目的地生成属于后续任务，不在本轮混用。公交服务计划可能只有一个合法选项，必须报告候选自由度，不伪造专属路线提升 GAF 分数。A 与 B 不混在一张总体分数里。

所有反馈共享请求和随机种子。四个末端策略严格共享同一候选池和 K；采样中反馈的主比较固定总计算预算，末端对照获得相应预算，候选数不强行声称也完全相同。执行前固定网络/教师调用的计费规则，分别披露候选数、去噪调用、教师调用及实测耗时，不把有测量波动的运行时间称精确等时。既报告全候选生成质量，也报告选出数据的质量，失败请求不能消失。

### 5. 以合成数据的可用性收尾

先完成盲于教师的物理与多样性评价；若交付数据的独立物理质量及覆盖没有改善证据，不拿高分类分硬推数据增广。末端策略共用候选池，因此判断其收益应看选出数据，不能要求共同池发生变化；同时报告全池质量。预定来源仿真训练子集固定，做 observation-only、observation+同量随机生成、observation+GAF 生成与等量重复观测控制；在新冻结留出仿真观测上评价两个独立序列模型，不让筛选教师兼当唯一裁判。历史 real-only 名称指来源观测，不是实测道路交通。失败及无增益也写清，但不是用更多历史负表填正文。

## 必须展示的质量证据

- 道路：vClass 许可、方向/连接、站点顺序、起止误差、规划失败与未完成率；结构保证的合法性不归因于 GAF。
- 运动：时长、均速/p95、加速度、停留比例/最长停留、最长巡航、四秒速度变化、弧长的逐类分布距离；按弯道/站点等道路上下文分析。均速或行程单项不足以代表运动模式。
- 多样性：同条件候选分离、路线覆盖、类内模式分布及训练近复制；质量改善伴随模式收缩必须同时呈现。
- 证据强度：配对请求、parent/场次相关性及模型种子分开处理；多个端点不能只挑显著的一项。新随机数实现、同线路新车辆、未见线路三种范围分开。
- 图：固定首例、按预先规则选出的长公交与弯路示例，地图轨迹+速度/加速度+GAF 同页；以全部样本的分布表为依据，示例不是统计结论。

## 正文重构：八章，而非逐实验流水账

1. 引言：生成完整且有类别运动的道路轨迹，研究问题与交付。
2. 相关工作：路网轨迹生成；完整时序扩散；GAF/时序表征；可控生成和评价。每节写与本工作的差别与空缺。
3. 数据与任务：CNR、原生 MoST、需求失配诊断和事件/划分协议，G29–G31 压缩为必要依据。
4. 生成方法：路线条件、物理时间表示、扩散、时长机制、道路解码。
5. 双视图 GAF 反馈：继承边界、教师训练、两种任务、末端与采样中机制、公平控制。
6. 实验设计：对照、数据权限、预算、指标与独立评价。
7. 结果：先生成质量，再 GAF 增量、适用条件和增广；旧负结果只保留解释设计选择所需的证据。
8. 讨论与结论：得到什么、未得到什么、泛化与资源限制、可复现实物。
