# 五类合成主线与后续数据扩展

状态：2026-11-07，论文结构已调整；以下新增仿真是设计方向，未启动、未形成结果。

## 当前可交付的研究问题

给定类别和许可路径，扩散模型生成完整时间戳坐标序列。原Hilbert空间GAF与速度GAF提供两个类别反馈视图，比较同池Uniform/S/V/SV的真实运动质量。公交、摩托、私家车、自行车、出租/网约车全部保留，不以公交停车代替全任务。

当前29,895训练腿/24,073父车辆，7,230开发腿。五类固定案例与类别物理矩阵已经存在，不需要新增仿真才能把另三类写进正文。原生时间与257点对比是表示消融，仍保留；旧新数据规模比较属于支持诊断，不是scaling law。只有两个同时改变数据覆盖、训练曝光与时长先验的设置，不足以估计规模规律。

## 下一批数据的优先级

1. 先做五类的独立场次复核：预先固定新仿真随机种子与时间窗口，保留自然服务结构，全部原始请求和失败分母。覆盖更多许可路线，记录路线模板是否跨训练/评价共享。用于检验空间GAF—摩托加速度、速度GAF—自行车加速度、公交停走等已有假设，同时保留不利速度/出租车指标。不能按结果挑类别策略。
2. 扩充训练时优先补公交、自行车、出租车的不同服务/出发环境，而不是再让私家车数量压倒其他类。自然比例评价与类别均衡训练抽样分开报告。新仿真车辆不等于新路线模板；重复模板数量、父车辆和独立场次数分别计数。训练、开发和评价场次先划分，避免仅换随机ID后漏入两侧。
3. 新车型作为单独扩展域：货车/配送车等仅为候选，先审核已有公开场景是否提供相应车型、道路权限和需求/停靠定义。缺失时新增定义必须公开记录，不能称原CNR已有类别。不要只设置互不重叠的最大速度使分类任务人为简单；新旧类别保留可重叠运动范围。新类别需重新训练对应类别头、扩散条件，并验证原五类未因合并标签改变任务。
4. 数据量由覆盖和资源预算决定，不把10万条或更多当作理论贡献。先有小规模产出/磁盘/完成率估算，再锁定有限仿真队列；保留现有约50GiB可用空间的安全余量。渲染并非SUMO数据生成的必要过程，不恢复已删除Isaac Sim。

## 下一轮生成实验应补的关键控制

- 在固定数据、候选数、采样步数和时长先验下比较Uniform、空间GAF、速度GAF、双视图，以及匹配的非图像类别反馈。
- 不以CNN自身分数为生成收益；主要保留原生速度/加速度分布、停走/巡航、条件多样性、覆盖和全部车型。
- 如设计特征匹配/采样中guidance，作为新方法单独固定权重与阶段；当前论文只声称已完成的末端选择。
- 有限新场次支持复核后再更新论文结果；旧冻结测试不用于模型/策略选择。
