# 从轨迹表征到路网约束轨迹合成

## 主问题
给定许可路线、交通参与者类别和随机噪声，生成到达终点的完整时空轨迹，同时保持各类在巡航、加减速、停车与行程时间上的分布和类内多样性。地图决定可行空间，扩散学习如何沿道路运动。当前路线由外部规划模块提供，论文应称 route-conditioned，说明它实现了 map-conditioned 的一部分。

## 可检验的研究假设
同一条带时间戳轨迹有两种读法。空间 Hilbert 图压缩有序位置，速度角场描述从位置差和时间差计算的速度之间的关系。二者可能分别保留车型相关的空间与运动结构。它们都经过压缩和归一化，信息保留程度需要实测。把两支按相同车型标签学到的特征用于去噪训练，可能帮助模型保留有意义的变化。

这个假设包含三个独立证据环节。第一，独立场次的真实轨迹上，各分支能否读出车型，拼接后是否有额外信息。第二，同一轨迹的表征是否帮助扩散学习，超过只给车型或类内错误配对。第三，最终合成数据是否改善独立物理指标，同时保留道路合法性和多样性。任一环节失败均限定相应结论，不将前一环节视为后一环节的证明。

## 方法
训练数据是一条完整、到达确认的 SUMO 行程。两个自行训练的 CNN 分别读取原空间图和速度图，输出512维隐藏特征。教师固定后，真实行程的干净特征作为监督目标，对齐加噪轨迹进入扩散网络后的中间隐藏特征。总损失包含标准去噪误差和0.1倍表征余弦误差，按信噪水平 alpha-bar 加权。双分支取平均。教师不需要把离散 Hilbert 操作对坐标求导。

推理时只需要道路、车型、噪声。模型联合生成总时长与沿路进度，输出每0.25秒的位置并附加确切到达时刻。真实未来的图像、特征、速度、时长均不进入推理。此前学到的六模式控制单列为已有研究，G28 不额外输入该模式，便于识别双表征监督本身的增量。

## 核心实验表
| 生成器 | 监督信息 | 能检验的问题 |
|---|---|---|
| B | 去噪目标 | 标准条件扩散基线 |
| P | 两支类别原型 | 额外类别监督是否足够 |
| S | 本行程空间特征 | 原编码的增量 |
| V | 本行程速度特征 | 动态表示的增量 |
| SV | 本行程两支特征 | 互补监督能否叠加 |
| SH | 同类相近路长的其他行程特征 | 正确配对的类内信息是否必要 |

两种子、相同步数、同批次、同初始噪声和候选数量。生成后直接评价所有候选。主要比较 SV-B，其他为机制解释，不从多项指标中挑一个有利结果宣称整体有效。教师评分只做次要证据，主结果由参考 SUMO 轨迹的物理分布、道路检查和多样性决定。

## 论文叙事顺序
1. 定义完整轨迹合成与道路条件，解释只匹配路径和行程长度不能保证运动合理。
2. 说明继承的 Hilbert 编码与新增速度视图各保留什么，并展示同路径改变时钟的编码敏感性实例。
3. 真实数据上先检验同标签分类、两支互补性、路线和物理统计基线。列出混淆矩阵与 SUMO 默认参数，解释类间重叠。
4. 给出去噪中间表征监督与道路解码的明确数学定义，说明训练时可见和推理时可见的信息。
5. 依次报告生成质量、类内多样性、配对打乱与类别原型对照，以及道路约束和失败样本。
6. 把既有筛选、采样中梯度、像素损失和分段归一化实验归为前期研究，每项说明具体检验的假设，保留负结果。
7. 新车流的同地图复核支持场次泛化。地理泛化、真实交通泛化、增广下游效用分别需要额外证据。

## 结论强度规则
如果双支提高分类而物理生成未改善，只能声称互补类别表示被观察到。如果 SV 好于 B 却不优于 P 或 SH，不能归因为同行程运动语义。如果 V 与 SV 相当，只支持速度表示迁移。G28 本身还不能证明 GAF 优于同预算的原始时序编码器，这需要单列的表示对照。与经验轨迹迁移相比的优势仍需相同场景对照。

论文的最终结果段在 G28 指标完成并核验后填写。研究路线借鉴 REPA 对齐干净教师表示与去噪隐状态的机制，轨迹任务上的有效性由本实验决定。
