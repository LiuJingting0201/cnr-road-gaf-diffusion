# G24 — cross-representation guidance inside complete-trip sampling

Primary question: does guidance from the frozen speed-mode GAF increase the *other*, spatial Hilbert–GAF network's final probability for the requested participant? The spatial network is sealed until sampling ends. No speed input to the spatial network; no participant output from the speed network. Target speed mode is drawn from G23's training-only class/route-length prior. Use eight fresh same-map SUMO episodes 276001–276008, first three accepted starts per class and episode in ID order. Freeze both G22 seeds, same four initial noises and 100 DDIM denoising steps. Preserve actual endpoints. Do not inspect either reserved test.

Fixed intervention: modify the predicted noise during denoising using the normalized gradient of log target speed-mode probability through a predicted clean trip. Decode its duration and progress to a differentiable one-second along-road speed image. The hard-binned MTF participates in forward scoring only; GASF/GADF supply gradients. Stop gradient through the denoiser when computing this direction. Smooth weight 4*a*(1-a) where a is cumulative alpha; signed RMS noise correction 0.05 times this weight. This avoids selecting an individual denoising step. No strength sweep. Compare unguided, class-directed guidance, and a matched-strength control with target modes permuted among requests (same global target histogram). Record compute overhead.

Primary endpoint: requested-class spatial probability under guided minus unguided, class-macro, averaged over all four draws and both weights. Pair uncertainty over complete simulation episodes, conditional on trained weights; secondary top-1 fraction, speed-target probability and independent SUMO time / sustained cruise / four-second-change discrepancies. Compare sampling-only fixed uniform slot to ordinary terminal speed reranking and compare both four-candidate pools after terminal ranking. Same candidate and denoiser budget; gradient evaluations cost extra. Keep all classes, bounds and failed encodings. No tuning on results.
