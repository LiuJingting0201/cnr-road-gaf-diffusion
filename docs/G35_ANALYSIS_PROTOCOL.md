## 分类分析（读取新分类结果前固定）

在同一份G35新开发完整leg上比较旧G33与新G35的空间/速度教师。新教师使用完成且校验过的保存logits；旧教师在同一新输入上只做推理，分别验证原训练缓存与新输入缓存的来源，不把旧权重来源改写成新训练。核对两套训练parent与新开发parent均不重叠，另报旧开发parent在新开发中的重复身份。

固定准确率、宏F1、加权F1、每类F1/召回、混淆矩阵、NLL/Brier/ECE及训练—验证差距。主表按leg计算，另给每parent总权重相等的敏感性结果。按真实类别分层，对parent进行2000次配对bootstrap，seed35055，同parent全部legs共用重复次数，四个模型共用抽样。区间只条件于现有单开发场次、公共线路与固定权重，不称跨城市或未见线路泛化。

新旧都训练50轮，因此扩容后优化更新数增加。共享验证上的差异属于数据规模/时间覆盖/训练更新共同改变，不写成纯样本数量的因果收益。新的四个扩散模型固定10000步，虽更新数相同，样本重复率与有效点数、计算量仍不同。

工具scripts/g35_teacher_audit.py只读验证、推理与统计，不重训、不挑checkpoint、不设置“分数够高才继续生成”的门槛。先前小数据教师训练集已接近满分；如新验证仍弱，先查类别支持、逐类混淆、分布和编码裁切，不无限换CNN。任何具体代码错误修复都另存失败与新尝试。
