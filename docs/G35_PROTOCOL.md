## 有限仿真与分区

- 两个训练场次：350101、350102；一个开发场次：350201。各自运行全10小时、0.25秒步长。运行队列固定且不重复启动。
- 全部交通参与仿真，仅关闭person的FCD记录以节省磁盘；车辆仍每0.25秒记录XY、type、speed、lane/edge、pos。保留tripinfo、实际路线与exitTimes、停站事件、summary和日志。额外字段用于完整leg提取与审计，不冒充事前生成条件。
- 既有CNR实体沿用原train/val分区，旧test模板仅按ID/split元数据排除，不读取旧test轨迹/结果。未知parent沿用G30固定哈希分区。训练episode仅接收train parent，开发episode仅接收val parent。
- 训练parent在查看完成情况前固定选择一个实现：`int(SHA256('g35-realization-v1:'+base_id),16) % 2`映射到`[350101,350102]`。只保留该场次的合格完整legs；缺失/未完成不从另一个种子补齐。不同种子不能算新车辆来源。
- 普通车按原计划活动停车事件划leg；公交保留整条已完成服务及途中停站。复用G31事件和覆盖规则，原生时钟连续、至少2点、端点误差不超过0.25秒、无超过100m/s坐标跳变。保留排除原因与未完成数量，不截短长行程凑样本。
- 目标为至少10,000个独立训练parent的完整legs，并要求训练/验证均支持五类。实际以完成回执为准。全部停留段保留；完全零路长的leg另列为现有运动模型未支持，若存在则阻止自动训练，不能静默删掉。

## 模型与GAF

完整数据检查通过后自动训练，不另设分类准确率筛选门槛：

1. 复用G33直接运动扩散模型，原生0.25秒与257点匹配对照，各seed42/43，共4次拟合。每次固定10,000步、有效batch64、width64、学习率2e-4，训练侧时长先验与长度分桶沿用G33；训练最终EMA，不按开发分数挑checkpoint。报告完整行程数、parent数、每类数量、点数、时间与显存。与旧pilot相比改变了时间覆盖和需求支持，不将效果变化单独归因为样本数。
2. 在相同新五类队列训练空间/速度两支ResNet18，各seed42、50轮、final-only，保持G33优化器与类权重。空间使用继承的Hilbert→GASF/GADF/MTF三通道、原冻结网格及归一化；不加入速度特征。速度由同一轨迹的时间与XY推导，沿用原128点速度摘要及角场，不把它称为原空间编码。二者均预测参与者类别，均为本项目自训CNN。
3. 原生目标保留精确有序路径顶点与时间进度；生成输出仍是带时间的道路轨迹，不是GAF图像反解。训练观测路线是监督；正式生成不得读取参考未来路线/时长。另存未改动的原始XY供空间GAF，避免重构浮点误差影响Hilbert网格边界；速度由同一XY推导，不用SUMO附带speed字段替换。图片缓存无损压缩并逐块检查像素相等。
4. 全日数据可能有小于5秒的有效完整leg。继承的速度函数同时计算未用于本分类任务的四秒变化量，因而原实现拒绝这些短leg；新缓存仅解开这一附带限制。至少1秒的leg仍取原一秒弧长增量并重采样128点，小于1秒的leg以观察弧长/观察时长的平均速度重复128点，单独计数。所有至少5秒的速度摘要与原函数逐值核对；不删短leg、不延长观察，也不声称亚秒常量摘要能表达完整加速度。

本队列到完成数据及4个扩散模型、2个教师后停止。训练完成不等于生成有效。下一次生成对照先固定新请求和参考场次，比较无GAF、空间、速度、双支的同预算输出，主看速度/加速度分布、停走/巡航、道路合法性和多样性；不会只凭教师分数更新论文。原CNR与新数据的类别/运动分布继续并列，已有冻结测试不回流。
