# 承接组内GAF工作的边界与纠偏

2026-11-04，按用户最新要求明确：本课题必须承接原有GAF工作和用户提供的SUMO数据，不能以新道路生成路线替代它。

## 原仓库中可核验的链条

原README明确描述：raw trajectory CSV → Hilbert序列 → GASF/GADF/MTF RGB → 图像DDPM。README同时说明图像到轨迹的解码尚未集成，图像FID仅为初步检查。

原仓库week04另有GASF(dx)/GASF(dy)/起点热图及解析恢复路线；week05包含位移数据与归一化实验。两者不能混称为同一原始Hilbert方法。应逐版本记录继承、修改和无法精确复现之处。

## 目前实际完成了什么

- 主要训练数据是用户给的midimost_with_class2.csv，六类，按车辆划分训练/验证；不是另找的新数据。
- 原Hilbert→GASF/GADF/MTF编码已实现数值核验及分类表示对照，但尚未在新统一协议下完成其图像扩散＋解码生成基线。
- 当前G4/G4b训练的是直接坐标扩散，用新训练的位移GAF分类教师作CE/KL反馈；TCN和打乱反馈为对照。它是扩展消融，不等于原生成链复现。这里的教师不是组内现成分类器，权重与输入版本必须写清楚。
- vehicle_positions_TS_New.csv已审计，但尚未加入这轮正式生成对照；不能宣称两份数据上的实验都完成。
- 道路路径＋进度原型尚未训练，已移出活动仓库到本地暂存，不再作为当前主线推进。

## 纠偏后的实验优先级

1. 补齐原GAF生成链的可运行基线：明确原Hilbert-RGB版本、训练协议和图像到轨迹解码条件；先测试真实图像的解码恢复上限，再评价生成图像，避免FID好而轨迹不可还原。
2. 与原仓库的可恢复位移GASF路线对照，记录分辨率、归一化、起点条件和信息损失；任何改造都需有原方法对照。
3. 在同一SUMO数据/划分上训练扩散模型，评价生成轨迹的形态、运动、路网一致性及类别语义；直接坐标扩散和G4反馈作为比较与消融。
4. 用生成轨迹增广原GAF分类任务，形成组内工作的下游闭环。不能只有新教师自评分，也不能只靠图像FID或点贴路率。
5. 第二份单类SUMO表补生成对照；未确定地图前不对其宣称路网合法性，不拿MoST地图硬套。

主线表述：从组内GAF轨迹表示与分类工作出发，研究其面向扩散轨迹合成的可生成性、可恢复性及路网/语义约束。已有反馈实验保留全部结果，但不再代替原GAF生成基线。
