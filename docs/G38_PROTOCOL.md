Locked before training/evaluation outcomes, 2026-11-09. Continues G37 under explicit user authorization. Main model factorization: map/OD/class/declared service stops → route preference distribution → route-conditioned temporal diffusion → optional GAF feedback → timestamped XY. The existing G35 native-clock diffusion and two GAF readers remain frozen to isolate the new route component.

## Training and scope

Use the G35 merged full-day metadata: 29,895 train legs / 24,073 parents and 7,230 development legs / 5,842 parents before route-support checks. Use emitted edge-instance sequences as **training targets**, never as prospective generator conditions. Split/parent identity must be disjoint; no old frozen test access. Record excluded routes and decision coverage per class. Static map coordinates, permissions, lengths, speed limits, bearings, next-edge geometry and shortest remaining distance are allowed features. Observed travel duration, exit times and motion are not route-policy features. No participant ID embedding.

Train a masked next-road categorical policy conditioned on destination (or next declared bus stop). This is behavioral cloning of observed route decisions, not a formal recursive-logit equilibrium model, and does not learn congestion interactions. Linear class-specific utility and a two-hidden-layer neural utility are matched controls, each seeds42/43, final checkpoint at4,000 updates, batch512, AdamW lr0.001/weight-decay0.0001, gradient norm5. Class then parent then leg then branching decision are sampled uniformly. Deterministic transitions contribute zero log loss and are reported separately. All admissible reachable successors enter each choice set; no negative-choice sampling. Bus public service templates are shared across partitions, not unseen-line generalization. First-passage-inconsistent segments and unsupported connections are excluded transparently.

Development readout: parent/leg-balanced branching-decision NLL, accuracy, multiclass Brier score and calibration; uniform and map shortest-remaining-cost baselines. Report seen/unseen exact OD edges within class, shared route fingerprints and bus/nonbus separately. Do not use validation outcomes to choose checkpoints, features or feedback strength. Four fixed fits; no retry sweep. The neural policy is the preregistered generation arm regardless of which validation score is better; linear remains a full control.

No ground-truth route is added to the catalog. Frozen native diffusion seeds42/43 each generate8 motion candidates/request across catalog routes. No diffusion retraining is needed for this controlled experiment. All selectors share exactly these candidate tracks and GAF scores; route policy fits42/43 pair with diffusion42/43. Four generation cells, at most3,200 tracks.

Route probability is the product of learned masked transition probabilities, then normalized over the supported catalog. Candidate weights divide route mass by that route's candidate count; thus a three-route pool is not biased by an8-slot allocation. Compare Uniform(route-balanced), Shortest, linear route policy, neural route policy R, S, V, SV, R+S, R+V, R+SV. Feedback adds log target probability with fixed coefficient1; SV averages the two log scores. Use coupled Gumbel draws at unit temperature, retaining probabilistic selection rather than deterministic maximization. Also retain the complete weighted distributions/entropy. Encoding failure uses a shared route-balanced fallback for all arms; report it. Equal candidate budget does not imply equal sequence lengths or equal wall time.

## Evaluation and stopping

Only after candidate completion, open new reference tracks/routes. Report every class and scene/model seed, all ten physical summary distances, native speed/acceleration W1, route-edge usage distribution discrepancy, expected route overlap (a descriptive similarity, not unique-path correctness), detour, effective route count, candidate coverage and nearest-catalog-reference overlap ceiling. Never label a valid alternate path incorrect merely for differing from the one reference. GAF own classification score is auxiliary. Selection effects must be compared with R on the exact same pool, including adverse endpoints. Two episodes and two model seeds are not four independent traffic scenes; no pseudo-replicate significance claim.

Main questions: (1) Does learned routing improve held-out decision prediction relative to map-only controls? (2) On the same finite catalog, does learned routing change distributional realism? (3) Does GAF improve independent geometry/motion endpoints beyond learned routing, without collapsing diversity? A speed/acceleration trade-off is not an overall improvement. Catalog failures and missing reference support retain their original denominators. Learned preference cannot repair routes absent from the catalog; catalog recall is therefore a required diagnostic.

Background: [Zimmermann & Frejinger, recursive route-choice tutorial](https://arxiv.org/abs/1905.00883); [SUMO route assignment](https://sumo.dlr.de/docs/Demand/Dynamic_User_Assignment.html). These motivate sequential choices and route distributions; this implementation does not claim to reproduce their equilibrium or recursive-logit estimators.
