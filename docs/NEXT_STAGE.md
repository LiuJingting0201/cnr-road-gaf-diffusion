# 后续实验决策：从贴路提升走向可用轨迹

依据：2026-11-04 的 R1/R1b/R2、G1/G2/G3 验证实验。本文是下一阶段计划，不是已实现贡献。

## 2026-11-04道路审计后的更新

有向车道匹配与两种半径敏感性检查已完成。完整验证集暴露了停留状态，254个偏离2m行驶车道范围的低位移窗口与公开停车中心线高度吻合。当前生成器经道路筛选后，5m整轨迹图一致性仍只有11.88%；该数值不是交通合法率。详细限制见[道路与停车审计](results/TOPOLOGY_AND_PARKING.md)。

下一步优先实现行驶/停留状态与允许区域的区分，再推进道路路径＋运动进度条件扩散；GAF反馈在这一基础上与同输入TCN公平比较。原先的匹配器构建任务已部分完成，行人walkingarea和停车状态整合仍待实现。

## 已有证据如何约束故事

1. 在64点和224点的新窗口协议中，Hilbert/GAF未优于直接序列分类。保留原精度与细精度Hilbert、位移GAF和同输入TCN，作为组内工作到新任务的可追溯比较；不能宣称复现或否定原论文。
2. 地图条件扩散改善精确车道距离，但约60%贴路率距离合法路径目标仍远。仅做图像分类或重新训练更大模型无法解决拓扑问题。
3. 位移GAF对固定候选池有语义筛选作用，但尚无相对同输入TCN的独特优势。GAF目前是待验证的反馈模块，不能写成不可替代的核心创新。
4. 道路筛选会偏向较短轨迹，几何、运动和类别一致性存在冲突。核心问题应是这些约束如何共同满足；不能只最大化分类概率或贴路率。

## 下一阶段顺序与验收门槛

### A. 道路连接与方向审计（优先）

解析SUMO lane/edge、internal lane和connection；先对真实验证轨迹做连通地图匹配，再评价生成轨迹。评价必须容忍最近车道歧义，尤其是平行道路、立交和路口，不能把逐点最近车道跳变直接判为不合法。车辆沿有向连接运动；行人与自行车规则分别核验，不强套机动车单向假设。

报告可匹配覆盖率、匹配距离、方向冲突、连接断裂、拒绝率；匹配不确定的轨迹单列。若真实数据本身在候选地图上大量失败，先排查版本和vClass假设。最终测试集仍封存。

### B. 在固定生成器上检验约束机制

先比较原始采样、地图距离引导、连接感知修正。固定生成起点、候选预算和随机噪声，报告修正位移、拒绝率、速度/加速度分布以及有效多样性。逐点吸附到最近道路只作弱基线，不能代表拓扑约束。

如果纯距离场引导仍切弯、逆行或跨路，进入道路路径与运动分离的生成方式：在可通行道路图上生成路线，扩散生成沿路线的时间进度与受限横向偏移。路线条件不得来自验证轨迹的真实未来；若使用真实路线，必须另列为oracle上限。道路图、类别条件和训练轨迹只用于拟合路线先验，测试/验证未来不能参与。

### C. GAF反馈的直接干预实验

使用可微的训练尺度位移GAF，与完全同输入的delta TCN对比；Hilbert/MTF量化路线保留为筛选基线。比较无语义反馈、GAF反馈、TCN反馈、标签打乱反馈，固定训练预算与地图机制。先验证梯度有限以及反馈不会压缩速度/多样性，再提交三种子训练。

引导强度只在预定验证网格内选取；评价同时使用不同架构的独立分类器、几何与运动分布，不能用参与引导的分类器为自己打分。若两种反馈都有效但GAF无额外收益，论文如实定位为反馈框架比较；不把确定性编码包装成新信息来源。

### D. 与组内分类工作形成可检验闭环

在训练车辆内设低数据比例，比较真实数据、重复采样、简单扰动、无反馈合成、GAF反馈合成、TCN反馈合成。每组相同合成预算、相同分类器训练预算和随机种子；最终仅在真实、未参与生成训练的车辆上评价macro-F1与各类召回。合成数据不能从测试轨迹的起点/路线生成。

若增广收益不存在，保留负结果，改用稀有类别覆盖、控制能力和几何/动力学质量的真实证据描述生成模型贡献。
