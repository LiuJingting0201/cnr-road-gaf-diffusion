# 毕设主线与下一批实验

2026-11-04更新；本文件取代此前以道路路径/进度模型为优先的安排。继承关系与未完成边界见[GAF_CONTINUITY.md](GAF_CONTINUITY.md)。

## 研究主线

使用用户提供的SUMO轨迹数据，承接组内Hilbert/GAF表示与分类工作，研究扩散轨迹合成及其路网一致性。原方法应有可复现基线；GAF用于生成表示、语义约束或下游增广的价值分别验证，不预设哪一种必然有效，也不要求所有最终模型都必须在图像域生成。

## 下一批工作顺序

1. **恢复基线**：固定原Hilbert→GASF/GADF/MTF RGB版本，量化真实轨迹经过编码和解码后的误差、信息损失与路网偏离。严格区分附带起点/尺度元数据与不附带的恢复条件，不能把真实未来信息用于生成。
2. **扩散基线**：在相同车辆划分下训练原表示的图像扩散与可用解码器，完整评价还原轨迹；同时复现原week04/05可恢复位移GASF分支，显式记录和原方法的差别。图像FID不能代替轨迹质量。
3. **方法改进**：在上述基线上研究可恢复表示、路网条件或约束；相同数据和预算下与直接坐标扩散比较。每次改动须能解释解决哪个实测缺口，不能直接把另一套道路生成模型当作组内方法的延续。
4. **组内分类闭环**：以真实留出车辆为评价对象，比较真实数据、重复采样、简单扰动和扩散合成增广对原GAF分类任务的效果；控制合成数量和训练预算，避免只用反馈教师自评分。
5. **第二份数据**：vehicle_positions_TS_New.csv为单类SUMO数据，补生成与恢复实验；对应地图尚未核实，不使用MoST路网评价它。

原Hilbert RGB归一化和量化可能丢失恢复所需信息，必须实测后报告。若需要修改编码或学习解码器，分别保留原始表示与修改表示的对照；不能把改造后的结果写成原方法复现。

## 已有结果的定位

主要正式训练数据为midimost_with_class2.csv。42次表示分类训练、9次道路条件扩散和候选筛选用于选型与支撑；G4/G4b共16次20,000步训练已完成，包含三种子CE反馈及单种子KL反馈。它们是新位移GAF教师的扩展消融，不是原Hilbert图像扩散生成基线。

三种子结果尚不支持GAF反馈稳定改善生成：无反馈/GAF的5m点贴路率58.03%/54.95%，独立TCN语义一致性61.28%/58.85%，独立GAF审计53.12%/54.17%。单一审计器的小幅上升不足以证明整体收益，完整结果见[汇总](results/semantic-followup/REPORT.md)。这些结果不能外推为原Hilbert/GAF工作的价值判断。

道路路径/进度原型尚未训练，已移出活动仓库暂存。停车与路网配准作为数据解释和评价边界保留，不扩大为独立课题。当前结果均为验证集探索，未开展最终测试评价。

## 论文验收标准

形成可复现的数据协议、原方法对照、明确的生成方法、恢复与路网/运动/语义评价、多样性及记忆检查、多种子消融、分类增广结果。贡献按证据表述，不以训练次数或强行宣称GAF胜出来替代方法贡献。
