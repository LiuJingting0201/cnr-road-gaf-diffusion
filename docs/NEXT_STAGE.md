# 毕设主线与实验路线

2026-11-04按用户要求重新收束：**训练路网条件扩散模型进行轨迹合成，研究GAF语义反馈的实际作用。** 地图、停车和编码审计是支撑材料，不能替代生成模型训练与核心实验。

## 三个核心问题

1. 扩散模型能否学习真实轨迹的形态与运动分布，生成有多样性的新轨迹？
2. 如何把道路连接、方向和几何条件融入生成，而不是只在输出后筛选？
3. GAF反馈能否改善目标类别一致性，或让合成轨迹提升真实留出车辆上的分类？

## 直接执行的训练链条

### G4：训练期语义反馈干预（当前执行）

四组共享地图条件扩散：无反馈、冻结位移GAF反馈、同输入位移TCN反馈、打乱标签GAF反馈。各20,000步，同初始化、训练批次和噪声流。低噪声预测轨迹的分类CE回传到扩散模型，教师参数冻结。这是生成器训练实验，不是GAF分类训练或生成后的候选筛选。

报告独立TCN与独立GAF双审计、道路与速度指标，不用参与反馈的教师给自己打分。先固定权重单种子验证机制，再对有效配置补三种子、反馈强度消融。既有自由XY表示尚不能保证图连接，此轮只隔离语义反馈作用。

### G5：道路约束扩散主体

重点实现道路路径条件与沿路径的运动进度扩散，让约束进入生成表示。路线由地图与训练数据先验提供；不能把验证轨迹的真实未来路线偷偷作为生成输入。原始XY扩散、地图条件XY扩散、连接感知修正作为基线；真实未来路线条件单独列oracle。

数据中存在与停车区域高度吻合的停留窗口，保留为数据协议事项：分状态评价，避免把合法停留误罚成离路。不展开独立停车系统课题。

### G6：把GAF反馈接到道路扩散主体

复用G4验证的机制，在相同道路生成器和预算下比较无反馈、GAF、TCN及打乱反馈。除类别一致性，还检验速度/加速度、整轨迹图一致性、输出多样性和记忆行为。GAF不必在单独分类任务上最高，但其生成收益必须能复现，且不能靠几何或多样性退化换取分数。

### 下游闭环：生成帮助组内分类

在训练车辆内设置低数据量条件，比较真实数据、重复采样、简单扰动、无反馈合成、GAF反馈合成和TCN反馈合成。相同合成数量及分类训练预算；最终在真实留出车辆上评估macro-F1和各类召回。测试车辆的起点和未来轨迹不得用于生成训练数据。

## 论文结构与贡献边界

主体围绕“道路条件扩散模型—语义反馈机制—生成与增广实验”展开。旧Hilbert/GAF编码和分类器作为研究基础、表示对照和反馈教师来源，数据审计放在数据章节或附录。

创新候选是道路约束与语义一致性如何共同作用于扩散生成；不能仅因把两个已有模块接起来就宣称创新。若GAF确有收益但未优于TCN，可据实定位为有效反馈实现与比较研究；若没有收益，不能预设正结论。硕士工作量由完整方法、消融、跨种子和下游验证组成，不靠无关分支或训练次数堆砌。
